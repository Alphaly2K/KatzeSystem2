# 全局设置

适用基线：CatSystem2 2.6.1.90。`settings::SystemSettings` 保存普通 359／360 使用的四块原始配置、790 查询的变量范围，以及 741／999／1050 查询的全屏、自动选择与场景动画选项。通过 `Default` 构造基线初值，依次覆盖启动、游戏默认及用户设置 XML，再放入 `CoreHost::system_settings` 或 `Runtime::host_mut().system_settings`。文件查找与读取由资源宿主承担。

## 用户配置写出

`write_xml(&mut XmlWriter)` 把当前模型持有的用户设置写入同一文档，包括窗口选项、消息／效果、旧声音通道开关与音量、系统声音、字体及功能开关。两种字体名为 None 时省略相应字段，保留从默认配置继承的语义；已指定名称沿用宽字符写出契约。数值保留原始 DWORD，以带符号十进制形式保存。

导出字段范围与用户覆盖对应。变量范围、纹理布局、自动速度预设和声音通道的运行记录由各自来源维护；四类有效音量在装载后通过 `refresh_sound_volumes` 计算。调用 `XmlWriter::to_bytes()` 取得完整文档，由文件宿主保存。宿主可向同一文档继续写入语言、按键和其他平台字段。 新声音分类的独立用户文档通过 `SoundConfig::write_xml` 写出，合并与继承契约见[声音配置](audio.md#系统语音配置选择)。

`LanguageState::apply_user_xml(bytes)` 覆盖 `language/id/UI`、`main`、`sub`，缺失字段先保留当前编号，再按启动前缀表长度检查。越界的三类编号均回退到 `default_index`；副文字的全一关闭值保持，默认编号自身不再裁剪。前缀表、默认编号及平台刷新请求保持。`LanguageState::write_xml` 写出当前三项原始编号。按键的用户覆盖及写出使用 `DeviceKeys::apply_user_xml`／`write_xml`，范围见[输入绑定](input.md)。

## 平台配置与完整文档

`PlatformSettings` 保存窗口／全屏尺寸、窗口与纹理选项、声音设备选项、D3D／DEPEND 开关、目录、TTS、`CONFIG/type` 和 `KEY/enable_joypad`。尺寸为两个 `[u16; 2]`，初始均为 800×600；其余整数保留原始 DWORD。`tts_parameters` 按 speed、tone 保存 float 位模式，初始为 1 和 0。三项目录依次为 picture、export、imgimport；None 保留宿主继承语义并省略写出，Some 空向量写出空字段。目录至多 259 个 UTF-16 单元，TTS 标识至多 63 个单元。

`apply_user_xml(bytes, supports_fullscreen)` 覆盖平台用户字段。窗口尺寸保存低十六位；全屏候选缺省取覆盖后的窗口尺寸，由回调检查原始 DWORD 候选，接受后才保存低十六位，拒绝时保留当前全屏尺寸。调用方应按平台当前可用模式实现回调。缺失字段保留原值，但 `ETC/disablemovie` 缺失时归零。`WINDOW/full_wide`、`ETC/cache`、`DEPEND/z32`、`DEPEND/use_z` 只写出，不从用户文档覆盖。浮点及宽字符沿用 [XML 字段契约](resources.md#脚本-xml-字段)。

`apply_startup_xml(bytes, adjust_fullscreen)` 使用启动字段路径：尺寸、帧率、限制及全屏选项在 `SCREEN` 下，屏保／伪装在 `GENERAL` 下，纹理过滤使用 `filter_min`／`filter_mag`，三维声音使用 `SOUND/use3d`，图像缓存及双核使用 `APP/imgcache`／`dualcore`，指针模式为 `CURSOR/mode`。全屏候选缺省取窗口尺寸，先保存低十六位再交给宿主调整，返回值同样保存低十六位；无显示设备时可直接返回候选。`ETC/cache` 缺失时取一。全屏窗口位置由 `SystemSettings::apply_startup_xml` 的 `SCREEN/mw_pos` 读取。

`settings::write_configuration(xml, system, platform, languages, keys)` 把主平台配置和用户选项写入同一文档。窗口全屏开关及位置从 `SystemSettings` 读取，语言从 `LanguageState` 读取；用户选项中同时写入配置类型、字体、手柄开关及启用按键槽。它与各模型的独立写出接口共用当前值。文件保存及装载后的设备应用由宿主执行。

普通 361 无参数，以状态二继续，不修改返回槽或配置变更标记。宿主需提供 `system_settings`、`platform_settings`、按键配置及 `ConfigurationServices`。独立宿主从 `HostState::configuration_keys` 读取按键；运行时优先使用输入设备的 `key_configuration()` 当前值，无设备配置时再取该字段。读取绑定不采集或提交输入状态。

`ConfigurationServices::write(task_id, file, bytes)` 同步保存完整文档，`ConfigurationFile::Main`、`Sound` 分别标识主设置和独立声音设置，路径由服务决定。打开失败、短写等普通文件失败返回 `Ok(false)`：361 继续，并在 `sound_config_enabled` 非零时尝试声音文件。此开关与 `use_jtalk` 独立。`Err` 用于集成诊断并停止调用；缺少所需模型或序列化超限同样返回诊断。`Runtime::set_configuration_services` 安装服务。

音频的立体声查询在没有显式 `HostState::sound_stereo` 覆盖时读取 `platform_settings.sound_stereo`，未配置平台模型时使用初值一。


## 默认值与 XML 覆盖

按启动、游戏默认、用户文档的顺序调用 `apply_startup_xml`、`apply_game_xml`、`apply_xml`。游戏默认文档覆盖 141 项声音、消息、效果、窗口颜色、系统声音及功能选项，保留当前字体名、字体控制、全屏开关和全屏窗口位置；用户文档还可覆盖这些字段。两种选项覆盖均不重算有效音量，由装载方最后调用 `refresh_sound_volumes`。

`SystemSettings::default()` 对应基线配置构造完成时的状态。声音部分包含 48 份旧通道配置，初始启用值为一，两处音量为一百，名称为空；总音量及四类音量均为一百，前四个有效音量尚为零。消息初值包括速度四、自动预设四、基础等待十五、字符等待五、历史上限一百和读过文字颜色 `u32::MAX`。效果及窗口选项分别保留基线初始值，窗口颜色为 `u32::MAX`。

`apply_xml(bytes)` 接受带 1.0／UTF-8 声明的原始 XML，复用资源 XML 读取规则。支持 VOICE 的音量、静音、连续语音及 play00～play47，MESSAGE 的速度、自动、跳过、阅读及历史选项，EFFECT 的效果和指针选项，以及 GAME 的 wndcolor／enabledrag／drawwnd／autoselect／enable_scene_anm、WINDOW/fullscreen 和 FULL_SCREEN/mw_pos。名称区分大小写，除下述字体 fixed 外，缺失字段保留原值；存在但无整数前缀的字段写零，其他值保留原始 DWORD，不裁剪、不归一化为布尔。多次调用按顺序覆盖，解析失败保留整份配置。

字体 XML 覆盖读取 `FONT/face`、`faceruby` 两个独立名称，以及 `FONT/shadow/around`、`shadow/rightdown`、`bold`、`proportional`、`fixed` 五项原始控制值。名称缺失时保留，显式空值清空；名称转换与 FES `font`／`ruby` 相同。`fixed` 缺失时使用本次读取的 `proportional`，因此空 XML 也会把固定字宽重设为当前比例字宽值。名称超过 63 个 UTF-16 单元时返回诊断并保留整份配置；字体字段校验在其他配置覆盖之前完成。覆盖后由宿主显式调用 `apply_message_defaults` 应用消息默认值，字体在目标平台上的可用性由字体服务检查。

`refresh_sound_volumes()` 将主音量分别乘以四类音量，先作 u32 回绕，再按无符号数除以一百，写入声音块前四个 DWORD；静音字段保持独立。XML 覆盖和普通 360 写回均不隐式调用此方法。启动宿主在加载游戏默认设置、覆盖用户设置后显式调用，再开始任务执行。此处的 48 份旧配置与声音任务的 64 个运行通道分别保存。

`apply_startup_xml(bytes)` 读取 `GAME/autoselect`、`SCREEN/mw_pos` 以及 `GAME/flag/local0`～`local7`、`global0`～`global7` 的 `start`、`count`。默认局部首项为 `[0, 512]`，全局首项为 `[512, 512]`，其余十四项均为 `[u32::MAX, u32::MAX]`。缺失字段保留，整数解析沿用原始 DWORD 规则；超出八项的节点不读取，XML 解析失败时保留整份配置。两组值表示变量编号范围，并非画面坐标。

启动覆盖还读取 `VOICE/v00`～`v47` 的 `voice`、`mastervol`、`head`、`group`、`int`。名称、文件前缀和目录分别至多 31、39、31 字节，保留 XML 的 UTF-8 及字面实体；显式空文本清空字段，缺失时保留。目录在每次启动覆盖时转换单字节 ASCII 小写，前缀保持原值；CP932 双字节保持。每个旧通道的播放开关均重置为一，随后由游戏默认及用户文档的 `VOICE/play00`～`play47` 覆盖。这些定义沿普通 359／360 的声音块读写，不写入用户配置文件。

启动覆盖还读取 `GAME/wndcolor/r`、`g`、`b`、`a`，各分量缺省取已有颜色的相应字节。`CONFIG_B/wnd_alpha` 缺省为一；非零时，Alpha 按有符号 DWORD 回绕乘一百再除以 255，转换为百分比。随后将 A、R、G、B 逐次移位并 OR 合成窗口颜色；分量不先截断。该转换在每次启动覆盖时执行。

启动覆盖同时读取上表的 TEXTURE 字段，保留原始 DWORD 和缺失值。区域单位为面块，依次为起始列、起始行、列数、行数；普通 542 使用八组区域及 `texture_16bit_row` 补建当前画布。`texture_32bit_row` 独立保存，542 使用当前画布的其余行作为 32 位区域。配置覆盖不创建或调整已有画布，宿主按尺寸和网格创建存储后显式准备面块。

自动推进预设的前十项初值为 `[5,7]`、`[7,8]`、`[8,8]`、`[12,7]`、`[15,5]`、`[16,9]`、`[17,12]`、`[21,11]`、`[25,10]`、`[29,10]`，其余二十二项为零。启动覆盖读取 `GAME/autopriset/p00`～`p31` 的 `base`、`char`，缺失分量保留，随后按当前消息块的自动速度编号更新基础等待和逐字等待。编号不在 0～31 时返回诊断。用户设置 XML 的 `MESSAGE/auto_p`、`base`、`CHAR` 仍按字段分别覆盖。

## 普通调用

606、607、844 接收一个待格式展开的文件名地址，忽略额外参数，依次返回旧声音记录的播放开关、mastervol 和编号。查询先按完整目录匹配 `int`：目录去掉最后一段的扩展名，比较忽略 ASCII 大小写，首项优先。未命中时，将完整输入的单字节 ASCII 转为小写，再按非空 `head` 查第一个前缀；不剥离文件名之前的目录，也不规范化配置前缀。路径扫描和小写转换保留基线 CP932 双字节。未匹配时，606／607 返回零，844 返回全一；命中时保留原始 DWORD。输入正文须短于 260 字节，查询不修改来源或配置，缺少全局设置时诊断，三项均以状态一返回。

605 同样先格式展开文件名，再查询旧分类的有效音量。主静音非零时直接返回零；否则先按目录查声音定义，未命中时按原始分隔字节提取文件名，再按前缀查定义。读取命中定义的 group，以此编号在 `HostState::sound_groups` 中查首项；bgm、se、voice／sysvoice 分别使用声音块前三路已换算音量及对应静音，类别名忽略 ASCII 大小写。没有定义、没有组或类别未知时返回 100；sysvoice 与 voice 共用第三路。查询保留缓存音量的完整 DWORD，不再次乘主音量。主静音分支跳过名称长度检查，仍保留此前的格式展开；返回状态一。

359 接受四个目标 VM 地址，按表格顺序复制完整配置块。360 接受前三块的三个来源 VM 地址，按同样顺序写回全局配置，保留 `window`。两者均为状态 2，不压入返回值。

每个地址分别解析普通区或外部区。地址 0 指向普通区首字节；起点不在存储区内的地址跳过该块，`u32::MAX` 可用于跳过。起点有效但剩余空间不足时返回越界诊断；前面已完成的复制保留。多个目标重叠时，后复制的块覆盖此前结果，不预先合并四块。

参数长度不符在复制前诊断。存在有效地址但宿主尚未配置 `system_settings` 时诊断；全部地址均无效时正常继续，无需配置。此接口复用当前 VM 的存储解析，扩展分配区沿解释器的存储能力继续接入。

790 接受 `[组选择, 项索引, 起始编号输出地址, 数量输出地址]`，返回状态一。组选择零读取局部范围，任何非零位模式读取全局范围。项索引按无符号值判断，小于八时返回一，依次向普通区或外部区写入起始编号、数量；地址零有效，同址或部分重叠保留写入顺序。其他索引返回零，不修改输出，也无需全局配置或有效输出地址。

两处输出地址在写入前确定。通过 `2B` 执行时，起始编号输出可覆盖已退栈的索引参数，数量随后按修改后的索引读取；组选择保持首次选择的组。若修改后的索引越界，或输出空间不足，库返回诊断并保留已完成的写入。独立 `Host::call` 使用显式参数，没有 VM 参数区。359／360 不复制或写回这两组范围。

999 不读取参数，返回 `auto_select` 的原始 DWORD，状态一。它与启动及用户 XML 的 `GAME/autoselect` 共用同一字段，359／360 不读取或写回该值。宿主未提供全局设置时返回诊断。

1050 不读取参数，返回 `scene_animation_enabled` 的原始 DWORD，状态一；非零值不归一化为一。构造及重置初值为一，游戏默认与用户设置通过 `GAME/enable_scene_anm` 覆盖，启动 XML 不读取该字段。359／360 不复制或写回该值。查询不改变 VM 存储，宿主未提供全局设置时返回诊断。FES `getconf` 的 `enable_sceneanm` 读取同一字段。

741 不读取参数，`fullscreen` 为零时返回零，任何非零开关值均返回 `fullscreen_mw_pos` 的原始 DWORD，状态一。它读取全屏配置，与绘图 enabled／active 开关分别保存。宿主未配置全局设置时返回诊断；359／360 不复制或写回这两个字段。配置覆盖只更新查询状态，平台切换全屏仍由宿主实现。

1053 接受 mode 和原始语言编号两个 DWORD。mode 零／一／二分别选择界面、主文字、副文字，其他 mode 跳过。编号不检查语言表长度、不归一化；仅当原选择不同才写入、将 `HostState::system_settings_dirty` 置一并向 `language_change_requests` 加入对应请求，主文字重复选择同样跳过。请求使用 `LanguageTarget::Interface`／`MainText`／`Subtitle`，保存发送任务编号；平台投递失败仍保持写入与变更标记。状态二不压返回值，声音配置块保持，不需要 `system_settings`。

## FES 配置读取

`getconf destination name [index [extra]]` 向共享数值槽写入配置的原始 DWORD。依次求值目标、index、extra；后两项缺省为零，`play` 使用二者回绕相加后的通道编号。名称区分大小写，未知名称保留目标槽，超出共享槽范围时跳过写入。主体、系统块及对象事件处理器使用同一宿主状态。

|名称|来源|
|:--|:--|
|`messpd`、`autospd`、`autoind`、`autospd_b`、`autospd_c`、`stillread`、`contauto`、`waitpcm`、`fullskip`、`enable_readcol`、`readcol`、`skip_speed`、`contskip`、`strscroll`、`ctrlmode`、`autoleft`、`enable_readselcol`|消息块中的对应选项|
|`effspd`、`effcut`、`autocur`、`autodel`、`dorama`、`motcut`|效果块中的对应选项|
|`wndcolor`、`dragwnd`、`wndframe`|窗口颜色、拖动及显示选项|
|`vol_`、`mute_` 加 `master`／`bgm`／`se`／`voice`／`play`|声音块中的原始音量及静音字段|
|`contvoice`、`play`|连续语音及旧通道启用值；通道编号不在 0～47 时返回零|
|`lang_ui`、`lang_text_main`、`lang_text_sub`|`LanguageState` 的 `primary_index`、`message_index`、`subtitle_index`；副文字初值为 `u32::MAX`|
|`enable_sceneanm`|场景动画开关|
|`fshadow`|首索引按有符号值取 `min(index, 2)`，分别访问轮廓、阴影、粗体；extra 不参与选择|
|`fontweight`、`fontprop`、`fontfix`|粗体、比例字宽、固定字宽的原始 DWORD|
|`sysplay`|系统声音播放开关，使用下面的索引规则|
|`activewindow`、`use_sceneskip`、`use_jtalk`|`always_active`、`scene_skip_enabled`、`jtalk_enabled` 的原始配置值|
|`screen`|`SystemSettings::fullscreen` 的原始配置值|
|`iswindow`|`HostState::windowed_mode` 提供的平台当前窗口模式原值|

`sysplay` 先检查 index 与 extra 的回绕和是否在 0～47，再以 index 本身访问数组。和越界时返回零；和有效但 index 本身越界时返回诊断。它与 `play` 使用的旧通道启用值独立。`activewindow` 是持续活动配置，实际前台及窗口状态由平台提供。`fshadow` 的负索引会访问基线字体控制区域前方，库返回诊断；extra 仍先求值。`font`／`ruby` 查询向共享字符串槽写入主字体／注音字体名，数值槽保持；未显式配置时沿用宿主默认字体。配置读取不触发对应设备或对象更新。

`screen` 和 `iswindow` 忽略已求值的 index／extra，分别读取保存的全屏选择和平台当前窗口模式，保留原始 DWORD。平台通过 `HostState::windowed_mode` 同步当前值；None 表示未提供，查询返回诊断。窗口示例成功创建窗口后提供一；无窗口宿主按自身模拟的模式显式提供。两项查询均可在主体和事件处理器中使用；对应写回仍返回未接入诊断。

## FES 配置写回

`setconf value name [index [extra]]` 依次求值 value、index、extra，名称区分大小写。支持上表的消息、效果、窗口、声音字段、系统声音及扩展功能开关，保留原始 DWORD；`play` 使用后两项回绕相加后的通道编号，超出 0～47 时跳过字段写入。`sysplay` 使用与查询相同的检查和访问规则，和越界时跳过字段写入。

`fshadow`、`fontweight`、`fontprop`、`fontfix` 采用与查询相同的选槽规则并保留原始值；成功写回同步 `HostState::message_defaults`，后续消息默认配置使用新的字形样式。XML 字体字段与这些命令共用配置状态。

`setconf string_index font|ruby` 从共享字符串槽取名称，缺失槽按空名称写回。两种名称独立保存，主字体写回同步消息默认字体。转换按基线逐字符规则处理：`FF FF` 对应单元 `FFFF`，孤立续字节或中间续字节不符时终止转换，补充字符保留首个 UTF-16 单元；查询逐单元返回 UTF-8，`FFFF` 还原为 `FF FF`，孤立代理项返回替换字符。截断 UTF-8 和超过 63 个 UTF-16 单元的名称返回诊断，保留原配置与变更标记；已发生的参数求值副作用保留。

`autospd` 同时从 `auto_wait_presets` 更新自动速度编号、基础等待和逐字等待；编号超出 0～31 时诊断且保留三项原值。`autospd_b`、`autospd_c` 分别只修改等待字段。`lang_text_sub` 选择已声明的语言编号，越界或负编号关闭副文字。`lang_ui`／`lang_text_main` 越界或负编号保留原选择，并正常完成音量刷新及变更标记；`lang_ui` 重复写入当前有效选择同样正常完成。改变界面语言或写入任意有效主文字编号时，立即更新对应选择并向 FES 通知队列加入刷新请求；主文字的重复选择仍产生通知。

FES 本轮通知处理时，语言刷新按原顺序发布到 `HostState::language_change_requests`。事件处理器中的请求保留到后续主体更新；预算续跑不重复发布。`LanguageChangeRequest` 保存发送任务和 `LanguageTarget::Interface`／`MainText`，不保存选择编号；平台宿主处理时读取当前全局选择，并在完成后移除已处理的请求。队列最多保留一百万项，发布失败时保留尚未发布的场景通知。界面文字、菜单及游戏字符串表的文件加载由平台宿主处理。FES 图像使用新的 `%LANG%`／`%LANG_M%` 前缀，在媒体更新时重载像素并保留图像包装句柄。

完整命令完成时刷新四类有效音量，并将 `HostState::system_settings_dirty` 置一，包括未知名称及无效 `play`／`sysplay` 编号。缺少 value 或 name 时保留已发生的参数求值副作用，跳过完成步骤。宿主在任务更新后处理配置变更通知并清除标记；用户配置写盘使用独立入口；写回不直接修改存档文件，也不重新配置已有文字对象。主体、系统块及事件处理器共用这些规则。已识别但尚未支持的配置键继续返回未接入诊断。
