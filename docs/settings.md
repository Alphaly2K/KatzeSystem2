# 全局设置

适用基线：CatSystem2 2.6.1.90。`settings::SystemSettings` 保存普通 359／360 使用的四块原始配置、790 查询的变量范围、999 查询的自动选择值及 741 查询的全屏选项。通过 `Default` 构造基线初值，依次覆盖启动、游戏默认及用户设置 XML，再放入 `CoreHost::system_settings` 或 `Runtime::host_mut().system_settings`。文件查找与读取由资源宿主承担。

|字段|字节数|用途|
|:--|--:|:--|
|`sound`|5628|声音参数及按通道保存的配置|
|`message`|72|文字速度、自动推进及消息选项|
|`effects`|32|效果与自动指针等选项|
|`window`|12|消息窗口颜色、拖动及显示选项|
|`local_flag_ranges`|64|八项局部变量范围，每项为 `[起始编号, 数量]`|
|`global_flag_ranges`|64|八项全局变量范围，格式同上|
|`auto_select`|4|`GAME/autoselect` 的原始配置值，默认零|
|`fullscreen`|4|`WINDOW/fullscreen` 原始开关，默认零|
|`fullscreen_mw_pos`|4|启动 `SCREEN/mw_pos`、用户 `FULL_SCREEN/mw_pos` 共用原始值，默认零|

块内字节按原布局保存，包括尚未开放类型化字段的部分。配置写回不自动触发设备、文字对象或绘图状态更新；这些应用入口继续独立接入。

## 默认值与 XML 覆盖

`SystemSettings::default()` 对应基线配置构造完成时的状态。声音部分包含 48 份旧通道配置，初始启用值为一，两处音量为一百，名称为空；总音量及四类音量均为一百，前四个有效音量尚为零。消息初值包括速度四、自动预设四、基础等待十五、字符等待五、历史上限一百和读过文字颜色 `u32::MAX`。效果及窗口选项分别保留基线初始值，窗口颜色为 `u32::MAX`。

`apply_xml(bytes)` 接受带 1.0／UTF-8 声明的原始 XML，复用资源 XML 读取规则。支持 VOICE 的音量、静音、连续语音及 play00～play47，MESSAGE 的速度、自动、跳过、阅读及历史选项，EFFECT 的效果和指针选项，以及 GAME 的 wndcolor／enabledrag／drawwnd／autoselect、WINDOW/fullscreen 和 FULL_SCREEN/mw_pos。名称区分大小写，缺失字段保留原值；存在但无整数前缀的字段写零，其他值保留原始 DWORD，不裁剪、不归一化为布尔。多次调用按顺序覆盖，解析失败保留整份配置。

`refresh_sound_volumes()` 将主音量分别乘以四类音量，先作 u32 回绕，再按无符号数除以一百，写入声音块前四个 DWORD；静音字段保持独立。XML 覆盖和普通 360 写回均不隐式调用此方法。启动宿主在加载游戏默认设置、覆盖用户设置后显式调用，再开始任务执行。此处的 48 份旧配置与声音任务的 64 个运行通道分别保存。

`apply_startup_xml(bytes)` 读取 `GAME/autoselect`、`SCREEN/mw_pos` 以及 `GAME/flag/local0`～`local7`、`global0`～`global7` 的 `start`、`count`。四块用户设置保持原值。默认局部首项为 `[0, 512]`，全局首项为 `[512, 512]`，其余十四项均为 `[u32::MAX, u32::MAX]`。缺失字段保留，整数解析沿用原始 DWORD 规则；超出八项的节点不读取，XML 解析失败时保留整份配置。两组值表示变量编号范围，并非画面坐标。

## 普通调用

359 接受四个目标 VM 地址，按表格顺序复制完整配置块。360 接受前三块的三个来源 VM 地址，按同样顺序写回全局配置，保留 `window`。两者均为状态 2，不压入返回值。

每个地址分别解析普通区或外部区。地址 0 指向普通区首字节；起点不在存储区内的地址跳过该块，`u32::MAX` 可用于跳过。起点有效但剩余空间不足时返回越界诊断；前面已完成的复制保留。多个目标重叠时，后复制的块覆盖此前结果，不预先合并四块。

参数长度不符在复制前诊断。存在有效地址但宿主尚未配置 `system_settings` 时诊断；全部地址均无效时正常继续，无需配置。此接口复用当前 VM 的存储解析，扩展分配区沿解释器的存储能力继续接入。

790 接受 `[组选择, 项索引, 起始编号输出地址, 数量输出地址]`，返回状态一。组选择零读取局部范围，任何非零位模式读取全局范围。项索引按无符号值判断，小于八时返回一，依次向普通区或外部区写入起始编号、数量；地址零有效，同址或部分重叠保留写入顺序。其他索引返回零，不修改输出，也无需全局配置或有效输出地址。

两处输出地址在写入前确定。通过 `2B` 执行时，起始编号输出可覆盖已退栈的索引参数，数量随后按修改后的索引读取；组选择保持首次选择的组。若修改后的索引越界，或输出空间不足，库返回诊断并保留已完成的写入。独立 `Host::call` 使用显式参数，没有 VM 参数区。359／360 不复制或写回这两组范围。

999 不读取参数，返回 `auto_select` 的原始 DWORD，状态一。它与启动及用户 XML 的 `GAME/autoselect` 共用同一字段，359／360 不读取或写回该值。宿主未提供全局设置时返回诊断。

741 不读取参数，`fullscreen` 为零时返回零，任何非零开关值均返回 `fullscreen_mw_pos` 的原始 DWORD，状态一。它读取全屏配置，与绘图 enabled／active 开关分别保存。宿主未配置全局设置时返回诊断；359／360 不复制或写回这两个字段。配置覆盖只更新查询状态，平台切换全屏仍由宿主实现。

## 核实范围与待办

原 359／360 入口批量运行 120 组，覆盖各块取舍、普通／外部区、地址零、两种区外地址、相互重叠及恰好写到区尾。返回状态、返回槽和完整配置／两份存储共 3,569,280 字节与库一致。

两项常规回归使用合成内存输入，固定重叠次序、零地址、部分失败、参数长度、三块写回保留第四块，以及两种预算下从普通任务写回配置再读取到外部区的路径。不依赖配置文件、原入口或设备。

四块用户配置构造的完整 5744 字节与原入口一致。XML 设置读取及音量换算另以 592 组输入检查两阶段完整配置，共 6,800,896 字节一致，覆盖全部受支持字段、缺失保留、重复节点、普通／十六进制前缀、高位及回绕值。新增一项常规合成回归固定默认值、重复覆盖、原始开关、大小写、通道边界、音量刷新时点及失败保留。

变量范围的 128 字节构造初值、76 组启动 XML 覆盖、360 组普通 790 查询及 32 组参数区覆盖均与原入口一致。查询核对返回状态、输出值及完整普通／外部存储；参数区覆盖由 Rust 的真实 `2B` 指令重放。两项新增常规回归只用合成配置、内存和指令，覆盖原始选择位、重叠写入、无效项、部分失败、参数索引重读及成功／失败后的调用上下文清理；已有配置回归同时覆盖启动字段及默认范围。

自动选择构造初值及 392 组两阶段启动／用户配置序列已通过完整原读取器核实。每阶段的配置字段和 999 查询状态、返回值共 784 份记录与库一致，包含缺失、重复节点、大小写、空值、非法前缀、高位和回绕值。现有合成回归覆盖启动后用户覆盖、缺失保留、忽略参数，以及普通任务在两种预算下读取同一全局字段。

全屏开关和 mw_pos 构造初值均为零。二十四组原始开关／值组合确认 741 的非零门控及状态一，另有 116 组启动／用户配置覆盖的两个字段和查询结果与库一致；包括字段组差异、缺失保留、重复节点、非法前缀及 DWORD 高位。既有配置与普通任务回归扩展这些字段，保持三项合成测试，不引入设备或外部输入依赖。

启动配置对自动预设等初值的修改、默认设置资源的自动装载、用户配置文件发现，以及配置与实际音频／文字／窗口服务的应用仍需接入。当前基线启动使用已核实的构造初值和游戏默认 XML。
