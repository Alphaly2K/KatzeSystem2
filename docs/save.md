# 存档数据与文件查询

适用基线：CatSystem2 2.6.1.90。`save::DataContainer` 提供 CSS 加载、编号记录及其生命周期；对象状态、数值区分组和场景恢复继续沿各自入口接入。

## 文件与记录

文件头为四个小端 DWORD：`CSS\0` 签名、压缩字节数、声明已用字节数、原始标签。头部后为 zlib 数据；文件扩展名不参与识别。声明用量按 512 KiB 向下取整后加 512 KiB，得到加载后的逻辑容量。

每条记录为小端 `u32 id`、`u32 length` 和 `length` 字节正文，记录之间没有对齐填充。相同编号可以重复；查询和删除只命中第一条。查找范围为逻辑容量，声明用量之外已经解压出的记录也参与查询。

`DataContainer::new(tag)` 创建初始容量 512 KiB、用量零的容器。`append(id, bytes)` 追加记录，`record(id)` 返回可借用正文或 None。`remove(id)` 成功时缩小逻辑容量和已用长度，保留底层分配；记录末端等于或超过逻辑容量时不删除。追加按已用长度跨越的 512 KiB 边界扩容，`clear()` 恢复初始容量和空用量，保留标签。`tag()`、`capacity()`、`used_len()`、`used_bytes()` 提供查询；声明用量因异常删除回绕后，超出分配范围的字节查询返回诊断。

`DataContainer::from_css(bytes)` 对非 CSS 签名返回 None。正确签名下，原加载器忽略解压返回值；库保留错误前已写出的内容和头部声明用量，接受校验错误、未完整结束的流、流后附加内容及声明／实际解压长度差异。不能使用要求完整流及精确长度的脚本解压接口替代这一契约。

`snapshot()`／`from_snapshot(bytes)` 交换嵌套记录使用的未压缩快照。头部四个 DWORD 为保留项、逻辑容量、已用长度、标签，随后紧接已用正文；保留项在原实现中为内存地址，恢复时忽略，库固定写零。恢复沿用快照容量，不按 512 KiB 重新取整；容量尾部清零，正文不足、用量大于容量或容量超过读取上限时诊断。快照和恢复对象均独立持有字节。

`to_css()` 按声明用量写出完整文件：四个头部 DWORD 后接最高压缩等级的 zlib 流，只压缩已用正文，声明用量之外的记录不进入文件。文件头不保存逻辑容量，重新加载按声明用量重新取整；声明用量超过逻辑容量、压缩区超过 u32 或文件超过读取上限时诊断。该接口只生成字节，文件位置与写入由外层存档服务完成。常规合成回归串联追加、删除、序列化、重新加载及声明用量之外记录的丢弃，不读取外部文件。

基线分配尾部没有初始化。库将新分配及未解压写入的空间清零，未复现旧堆残留；分配末端不足一个记录头时结束查找。截断文件头、声明压缩区超出文件、超过 64 MiB 的容量、记录正文超出分配范围及写入越界均返回诊断。

## 宿主服务与普通脚本

`save::SaveServices::read(task_id, name)` 接收格式展开后的 CP932 文件名，由提供者按该任务的存档目录读取，返回原始文件或 None。目录来自任务构造时保存的配置；服务应保留各任务的目录关联。当前库不自动发现平台目录或修改任务目录。存档读取独立于资源类别补全和归档读取。

通过 `Runtime::set_save_services(provider)` 或 `CoreHost::save_services` 提供读写服务。未提供服务时，实际读写返回诊断；提供者报告文件不存在、无法打开或无法完成写入时，247／245 返回零。替换服务不会回收已有容器。

`SaveServices::write(task_id, name, bytes)` 接收格式展开后的 CP932 文件名和完整 CSS 文件，覆盖已有内容，完成返回 true，文件操作失败返回 false；服务错误直接返回诊断。默认实现返回未接入诊断，已有只读服务可继续使用。启动示例创建配置的存档根目录后写入文件，不自动创建文件名中的子目录。

`SaveServices::modified_time(task_id, name)` 查询同一目录下文件的最后修改时间，以自 1601-01-01 UTC 起的 100 ns 计数返回 `u64`。`None` 表示文件不存在或无法打开；元数据查询失败返回错误。默认实现返回未接入诊断，已有只读服务可继续提供 CSS 读取，再单独实现时间查询。

`probe_startup` 与 `window_startup` 按启动 `FOLDER/save` 展开保存目录，相对目录以游戏目录为起点。目录标记使用平台应用数据目录及启动的品牌、标题，规则见[配置目录展开](resources.md#配置目录展开)。`KATZE_SAVE_ROOT` 可直接覆盖最终保存目录；CSS 文件读取、修改时间查询和配置保存共用此目录。使用空目录可验证首次启动及未读文字显示。

两个示例从此目录读取 `setup.xml` 和启动 `SOUNDCONFIG` 指定的声音用户配置；不存在、不可读或无效 XML 按缺失文档处理。启动设置先应用游戏默认，再应用主用户文档及声音用户文档，完成后安装当前按键绑定、语言表和有效音量。普通 361 经配置服务保存这两份文档，主文件打开或写入失败仍继续尝试声音文件。声音分类定义通过资源服务读取，散装目录优先于归档；资源和启动配置的位置独立于保存目录。

240 与 250 都先向目标发送命令 177。240 保存至共享区末端，保留数值的完整 DWORD 位模式；空范围、零槽数或起点在区外也追加空记录并返回一。保存不改变数值；后续修改数值不改变已有记录。重复编号继续追加，250 仍读取首次记录。请求槽数超过读取上限时诊断。

250 先向目标发送命令 177，取得共享数值区后才查找记录；目标缺失、已删除或未提供数值区时返回零，不访问容器。记录不存在也返回零。恢复忽略记录末尾不足四字节的部分，最多写到共享区末端，保留此前和此后的槽位，不修改 FES 局部区、命名值或字符串。记录和数值区均存在时返回 1，包括空记录、起始槽位在区外及零槽位复制的情况；零句柄只需首个参数并直接返回零。

普通对象的 177 通过 `CommandBuffers::data1` 写四字节非零可用标记，标记选择该运行时的共享数值区。查询消费当前分支，保留命令输出槽；已删除对象保留标记缓冲区。普通对象更新中也可查询，避免为了借用正在执行的 VM 而中断恢复。

242 允许来源与目的为同一容器，先捕获追加前的快照。252 创建独立句柄，来源与外层容器的清空、修改或释放均不影响恢复对象；删除后缩小的容量也保持。原生地址保留项以外的快照头部和完整正文已通过批量原入口对照。

对象反序列化及其他分组恢复尚未接入，继续返回未实现诊断。

## FES 槽号时间查询

`newsave destination first last` 依次求值三个必需参数，扫描有符号闭区间 `first..=last`，把最新文件的槽号写入共享变量 `destination`。文件名为 `save%04d.dat`，四位宽度包含负号，较长槽号完整保留；查询通过当前 FES 所属任务的存档目录执行，不走资源类别或归档服务，不读取 CSS 内容。

所有文件均缺失或 `first > last` 时写入 −1。时间按完整无符号 64 位比较，只有更晚时才替换；时间相同且当前槽号不是 −1 时保留当前选择。−1 同时是合法槽号和未选择标记，选中 −1 后，下一个成功查询的文件会无条件替换它，包括时间更早或相同的文件。

参数缺失时立即结束，保留此前参数已经发生的数值副作用；额外参数不求值。目的共享编号越界时仍完成扫描，最后跳过写入。范围超过一百万项或结束槽号为 `i32::MAX` 时返回诊断，避免原有加一回绕形成持续扫描。

Runtime 的普通主体、对象处理器及系统块均已接入。查询按预算逐文件推进，完成后一次写入结果；预算续跑和服务错误保留参数、当前选择及已完成文件，重试只重新查询当前失败文件。续跑保留所属轮的时刻、主流程等待及处理器位置。实际需要查询时未提供存档服务或未实现 `modified_time` 均返回诊断；空区间不需要文件服务。每条新命令重新查询指定范围，不跨命令缓存文件时间。


## CST 登记与历史记录

运行时的普通 385／386 将 CST 上下文中的登记或历史表写入、读出本容器的编号记录。保存使用追加规则，恢复使用首个同编号记录；不复制脚本或语言绑定。参数、格式和附加数据约束见 [CST 存档](cst.md#登记与历史存档)。


## 序列集合记录

普通 424／425 将序列集合的名称树保存到编号记录，或从首个同编号记录恢复；保存追加记录，恢复替换树。独立装载的文件正文与跨度保持，恢复后不依赖容器寿命。参数、树格式和异常输入约束见 [序列集合](kcs.md#序列集合)。

## 原始缓冲区与容器交换

普通 833～836 使用宿主持有的独立字节区。其地址支持加上块内偏移，并与不透明对象编号共用分配源，保留完整范围防止碰撞；地址不自动绑定为 VM 本地、外部或扩展存储。宿主通过 `HostState::raw_buffer(address, length)`／`raw_buffer_mut` 取得受检视图，允许零长度的块尾视图，越界及释放后的地址诊断。

835 的来源可从块内开始，复制长度须位于同一块内；字节数零仍追加一条空记录。836 的长度输出地址可位于本地或共享外部区，地址零有效；空记录仍返回可释放的非零地址。容器为零时 835／836 只读取首个 DWORD。缓冲区保留至显式释放或宿主销毁，创建任务退出或容器删除不回收它；835 登记后来源释放、836 复制后容器释放均不改变已复制字节。

分配后的原内存未初始化，库初始化为零。单块不超过 64 MiB，同时保留分配数量和虚拟地址空间上限检查；失败返回诊断。原入口的 224 组场景覆盖七种长度、零容器／地址、记录缺失、本地／外部输出和块内偏移，分配／释放状态、368 个复制字节及 57,344 字节完整 VM 存储与优化实现一致。常规合成回归串联生产任务退出、跨任务地址传递、容器独立复制、零长度、释放别名、重叠编号防护及受检范围，不依赖本机文件或设备。
