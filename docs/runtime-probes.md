# 原引擎核实记录

适用基线：Windows CatSystem2 **2.6.1.90**。本页保留可复用的合成输入、观察结果及核实范围，供解释器行为对照使用。

## 核实方法

在隔离的 32 位 Windows 兼容环境中调用基线可执行程序的原有函数。临时程序副本调整入口以加载验证辅助程序，并停用原入口的 TLS 初始化；解析器、求值器、优先级表、控制流整理函数、KCS 装载与指令处理均使用原代码。辅助程序设置所需的堆、变量和数据上下文。

执行剧情 KCS 的局部函数时，以合成记录提供场景读取、语言配置和命令名称查询，保留原指令处理、字符串存储／展开、字符替换、参数提取和数值求值。条件菜单核实在收集完成后停止，未进入界面调度。选项 getter 和正文映射另用合成语言表直接调用原函数核对。

这里核实的是指定函数的行为。完整游戏入口、渲染、输入、宿主任务调度和存档恢复尚未运行。验证材料及程序副本不纳入项目；后续复现需要相同版本的 x86 引擎、可运行的 Windows 环境及对应辅助调用程序，不属于常规单元测试。

非法索引使用额外的合成保护存储核实：即使声明共享区容量为 1024，读取和写入 `#1024` 仍访问对应底层槽；负索引也直接访问前面的存储。局部变量读取同样可越过声明边界；局部写入另有上限 512 检查，越界进入引擎错误处理。另已追踪配置及启动调用链，本次共享区实际创建参数为 2048；该结论独立于越界探针。

本项目以脚本错误报告非法存储访问，保留有效输入的求值结果；不复现对宿主内存的越界访问。

526 组数据含 40,828 个对白输入块；本地化表共有 40,861 条。33 条差额逐项对应 13 个末尾选择菜单的选项文字。

再将全部 13 个实际菜单交给同一收集路径，分别设置条件变量为零／非零，共 26 次。每种状态保留 29 项，索引全部连续；七个条件菜单各保留两项。默认语言对照全部相等。四个菜单还各有一条未读取的末尾本地化条目，默认语言内容与前一条重复。33 条的资源归属与 29 条的运行读取数应分别记录。

直接调用原选项读取函数，以输入区间数 4 和合成本地化表验证：序号 0、1 读取条目 3、4；正文 `first<U+001F>part` 得到 `firstpart`；空条目、越界及缺失语言返回长度零。片段连接遇第一个空片段停止。

## FES 控制流整理

直接调用原条件结构整理函数，使用四个合成块核实正常条件、多余尾部 `endif`、开头孤立 `endif` 和 `if/else/endif`。正常块扫描到末尾；孤立终止符使当前层在该位置返回，其后语句不再由本次调用整理。

## KCS 批量装载

全部 103 份程序交给原装载函数，均成功装载。独立读取 2,113 条字符串初始化记录，构建清零后再复制字符串的预期存储，与原装载函数产生的整个数据区／栈预留区逐字节相等，103 份全部通过。

据此确定代码区长度、字符串初始化表、目标数据地址、数据区大小、栈预留大小及解压容量字段。

按原指令处理函数确定操作数数量，103 份代码区共完整解码 160,346 条指令，使用 53 种 opcode；18,048 个静态分支与调用目标全部落在指令起点。每个编码操作数为一个类型字节加四字节载荷，包含从运行栈取值的形式。

使用返回状态可控的合成宿主函数调用原 native 指令处理函数，覆盖状态 0～5。确认返回值入栈、继续／让出，以及状态 5 恢复参数并退回调用指令；结果表见 [KCS](kcs.md)。这次执行的剧情函数同时覆盖了代码调用、返回、局部帧、参数传递和原宿主接口调用。

## KCS 数值与存储处理函数

批量直接调用原指令处理函数，共 652 个合成用例。覆盖有符号／无符号运算、浮点位模式、NaN、零除数、窄目标、前后置自增减、复合赋值、压值、栈值写入、块复制、区间分支和四种转换。Rust 执行器与原结果的栈长度、结果 DWORD 及目标 DWORD 全部一致。

据此修正了早期 opcode 分组及类型推定：`06`／`07` 是 AND／OR，`09` 是 XOR，`0A`／`0B` 是移位；普通右移补零，后置自增减返回旧 DWORD，`25` 的解引用固定读取四字节。完整规则见 [KCS](kcs.md#数值与类型语义)。

另调用数值及字符串 native，确认已有数值区时 209 保留原容量和内容，210 越界返回零，211 的写入不返回栈值。278 支持带符号、十六进制和 32 位回绕的字符串编号；小数形式保持原文，缺失编号展开为空串。

519 的分隔符是半角空格，保留圆括号中的空格，双引号本身不提供分组。字母后接左括号时分词；`cmd a(b)c(d)` 得到 `cmd`、`a`、`(b)c`、`(d)`。`(:text value)` 去掉包装后作为一个词项，后接无空格后缀时继续拼接；空的 `(:)` 会结束零分隔词项表的读取。

## FES 宏展开

直接调用原宏登记与展开函数，核实同名定义覆盖、单次词替换、命令名替换、引号保留及数字边界。`A→B`、`B→9` 时 `A` 输出 `B`；字符串中保留原词，普通路径片段则参与替换。原引擎的行读取链先展开字符串引用，再展开宏。

## ANM 指令及随机范围

使用合成时间线调用原动画推进函数，覆盖全部 18 种指令和 0／1／2 参数类型。随机入口由探针提供固定 u32 值，其余区间计算及指令执行仍由原函数完成；同时计数随机调用。122 个用例与 Rust 的指令位置、持续时间、变量、五项显示属性及随机调用数全部一致。

确认 `loop` 在变量为正时减一并继续，非正时跳转；条件指令直接比较参数值。两端相等不消耗随机值；其他范围用回绕后的 `max-min` 作为模数，正常范围排除上端点。混合、显隐和坐标保存原始整数；`max` 读取图像宿主提供的最大帧 ID。详见 [ANM](anm.md)。

时钟原入口另执行 2,340 次合成更新，覆盖两种有限控制流、十种速度位模式、零及正负初始等待、非零时间基点、重复时刻和 u32 时间回绕。与库的显示变化标志、持续时间、基点、指令游标、变量及显示属性全部一致。确认零／负等待按原值执行；速度换算使用有符号差值，origin 继续累加未缩放的持续时间。三份实际动画分别以三种速度推进，108 次状态及随机调用数全部一致。

对象时钟封装及重启入口另以 2,340 次合成调用对照，时钟、游标、变量、显示和变化标记全部一致。对象封装以当前基点替换最大无符号时刻，零基点在本次推进前初始化；重启仅重置游标、持续时间及显示，保留变量与时间基点。预算中的重启通过合成回归确认会丢弃执行续跑位置并保留此前的变量副作用。

## KCS 基础字符串与数值转换

直接调用普通任务表的字符串宿主，使用合成字节串和独立缓冲区。格式化覆盖全局、局部及外部地址、字符串递归、宽度／补零、浮点精度和特殊值；截断覆盖 CP932 双字节字符两侧的容量边界。词项拆分、负序号／表末提取、包含两端的拼接、分隔字节与 `\\t` 转义，以及字符串替换与通用参数提取均已核对。

另用 24 组输入核对 26：空串和无效前缀返回零，`12.5tail` 返回 12.5，不完整指数回退，支持十六进制和不分大小写的无穷／NaN。`1.0000000596046448` 最终返回 `0x3f800000`，确认先按 double 转换再舍入为 float。随后扩展 1,028 组固定生成的十六进制、长十进制、上下溢、舍入中点和空白输入，修正垂直 Tab 也属于前导空白后，全部结果位模式一致。NaN 返回值与格式化产生 NaN 文本是两个独立契约，详见 [KCS](kcs.md)。

## FES 对象声明

原声明函数保留文本、类型查询、名称／数量分解和表达式求值，以替身创建器记录请求，隔离图形对象分配。类型匹配不分大小写，省略数量创建一个对象，0 同样转为 1，`[(1+2)]` 得到 3。再次声明已有两个银行的对象但省略数量，会报告错误；明确数量则继续发出创建请求。

先执行宏声明再执行对象声明，类型宏仍被报告为未知类型，数量宏也没有替换为宏值，确认 `#DEFINE` 不调用宏展开。负数量会原样传给原创建器，本项目在此返回诊断，避免非法分配。原名称分解函数在空方括号路径不写入数量字符串，且基线未使用该写法；库同样返回诊断。

使用全部 50 份 FES 检查新对象创建请求：588 条声明均读取成功，累计 1,678 个银行；尚未通过图形／音频宿主创建这些对象。

## FES 初始化列
