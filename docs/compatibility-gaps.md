# 2.6.1.90 兼容缺口

逐槽核对统一注册表后，普通表的 28 个未注册槽位均属于麻将。两套主回归游戏的普通 KCS 分别直接调用 587／585 个不同编号，其中没有未注册槽位。三套实际挂载的 379 份 KCS 也已批量复查，未发现上述麻将编号的直接调用。附加功能按下表延期，库接口可先迁移。VN 兼容检查另行跟踪剧情中实际用到的资源、存档和呈现行为。

## 延期的引擎兼容项

麻将、壁纸、旧版社交发帖及下表其他附加功能统一保留在兼容清单中。当前库接口迁移不补齐这些接口；已接入的调用包装和宿主契约继续保留。
