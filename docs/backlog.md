# 回看日志

适用基线：CatSystem2 2.6.1.90。回看日志保存来源、输入段、显示行和姓名；其排版采用字节宽度，与消息页的字形布局分别处理。

## 配置与对象

`SystemSettings::backlog` 从启动 XML 的 `GAME/log` 读取配置。696 构造时复制配置，后续配置变更不修改已有日志。独立使用可通过 `Backlog::new(Settings)` 构造，默认保留一百段；`u32::MAX` 表示不限段数。

|路径|默认值|
|:--|:--|
|`col`／`prof`|40／4|
|`nameline`|1|
|`nameformat/first`／`nameformat/last`|空字串|
|`indent`／`nameindent`|1／0|
|`disp/mes`／`disp/name`|1／1|
|`space`／`escape`|0／1|

姓名前后缀保持 XML 的 UTF-8 字节及字面实体，容量各三十二字节，含结尾零；过长配置返回诊断。前后缀不会转换成 CP932。其余字段保留原始 DWORD。常规文本分行要求正列数及可前进的缩进；无效设置返回诊断。

`SystemSettings::backlog_static` 独立保存启动 `GAME/log/static` 的原始 DWORD，缺省为零。普通 852 以状态一返回该配置值，不查询日志对象；未配置全局设置时返回诊断。

## 普通脚本接口

句柄来自运行时共享编号源，存活至显式释放或 Runtime 销毁；创建任务退出不回收它。非零的失效句柄或其他类型句柄返回诊断。

|编号|参数|行为／返回状态|
|:--|:--|:--|
|696|忽略|构造，以状态一返回句柄|
|697|日志|释放，状态二|
|698|日志、来源格式地址、输入段、姓名格式地址、正文格式地址、标记、段间空行开关|追加，状态二|
|977|同 698，再加扩展 DWORD|追加并保存扩展字段，状态二|
|699|日志、CST 上下文、声音命令格式地址、连续显示命令格式地址|按历史顺序导入原始 CST 字节，状态二|
|1034|同 699，再加语言格式地址|按历史顺序导入 UTF-8 文本，状态二|
|700|日志、输出 VM 地址、行编号|查询该行所属段的姓名，状态二|
|785|日志、保留段数|立即裁剪，状态二|
|876|日志|清空，状态二|
|850|数据容器、记录编号、日志|序列化并追加存档记录，以状态一返回一|
|851|数据容器、记录编号、日志|读取首个同编号存档记录并恢复，以状态一返回一；记录缺失返回零|

状态二保留 native 返回槽。零日志跳过对象及后续地址访问；850／851 任一对象为零返回零。700 的输出地址零有效，可写普通区或外部区：非零日志先写空字串，再查询当前保留区内的零起始行号；无效行、段间空行或无姓名记录保持空字串。

698／977 依次展开来源、姓名、正文格式，首零截止；缓冲容量分别为 64、256、4096 字节，含结尾零。姓名出现 UTF-8 `＠` 时只保留其后的字节；CP932 编码的同一字符不触发这一截取。698 的扩展字段为 `u32::MAX`。相邻段的来源字节和输入段编号相同时拒绝重复追加，其他字段不参与判断；来源比较区分大小写。

### CST 历史导入

699／1034 读取 329 保存的顺序历史，不修改来源上下文的脚本或游标。任一对象为零时跳过后续格式和资源访问，保留原日志。有效调用先清空日志，再依次展开声音命令、连续显示命令及可选语言，三个格式缓冲区均为 64 字节，含结尾零。

不限数量时从首条历史开始。其他限制从末条向前累计各条的保存数量减一，达到限制后确定读取起点；累计使用带符号 DWORD 比较和回绕。随后顺序装载所选历史，逐项读取其保存的输入段数量，追加后再按日志限制裁剪。装载失败跳过该项，数量超过实际输入段时追加空段。扩展字段保存历史条目的原始零起始序号。

临时场景不执行独立上下文的语言登记，因此该基线的 1034 即使指定语言并读取了 CSTL，也使用基础 CST 的 UTF-8 回退；699 保留 CP932 字节。正文记录依次拼接，姓名记录分别截去首个全角 `＠` 及之前内容后拼接；分隔符编码与各自文本编码一致。最后对姓名和正文执行一次 `$strN` 替换，再交给日志分行。

声音命令按 ASCII 空格分词并跳过重复空格，命令词与配置完整比较且区分大小写。按参数顺序经 `sound` 类别补全，以散装优先模式查询可打开资源；空文件同样算存在，首次命中使本段标记为一。本段已有声音标记时，后续命令继续使用最近一次读取的文本缓冲。连续显示命令以原命令首个空格前的字节数与配置前缀比较，忽略 ASCII 大小写，不要求配置在该位置结束；只取紧接第一个空格的单个参数，交给 FES 数值入口求值并保留副作用。标记初值为假，跨输入段及历史条目延续。

段间空行开关初值为连续显示标记的反值；类型二等待记录重新取反值，类型三翻页记录在连续显示非零时将其置一。声音标记每段清零。回看窗口、字体和绘图对象继续在呈现接口接入。

## 文本与保留规则

姓名和正文分别预处理。`escape` 非零时移除 `\@`、`\r`／`\R`，并连同其紧随的 `\n`／`\N` 移除；其他转义保留字面值。`escape` 为零时消费日志支持的颜色、字号、位置和等待控制，数值支持可选符号及十六进制；不支持的控制仅移除反斜线，`\[` 和 `\\` 保持字面值。真实 CR、LF、Tab 保留。

`nameline` 非零时姓名单独成行；否则在 `disp/name` 非零时拼接到正文首行。姓名登记仍保存前后缀。普通字节单元必须严格小于剩余列宽，默认四十列的纯 ASCII 正文每行三十九字节；有效双字节字符占两列。`[正文/注音]` 作为整体消耗，列宽只计算斜线前正文，允许使用 `prof` 的额外宽度。以日文开括号起始的正文使后续行增加相应宽度的缩进。空白缩进优先使用全角空格，奇数余量使用 ASCII 空格。

原分行入口执行禁则扫描，但序列化显示行按其实际消费的来源范围保存；库保持该范围，不另用消息页布局重排。空记录仍占一个段。段间空行需要全局 `space`、追加开关均非零且已有显示行；空行不属于任何段。

裁剪只移除最老的超限段、其行范围及紧随的段间空行，保留来源和姓名登记表。段和行分别维护累计起点。空段保留原始零行端点，因此裁剪后的行起点可能前进而当前没有对应显示行。清空四张表，保留配置、数量限制和累计起点。

## 存档数据

`serialize()` 输出六个小端 DWORD：来源表、段表、行表、姓名表的相对偏移，以及累计段起点、累计行起点。每张表以 DWORD 数量开头。

来源和姓名逐项保存零结尾字节串。每段保存七个 DWORD：标志、来源表下标、输入段、首行绝对编号、末行绝对编号、姓名表下标、扩展值。标志位一表示非空正文，二表示非空姓名，四表示追加标记非零；无姓名下标为 `u32::MAX`。每行保存段的绝对编号和零结尾正文；段间空行的段编号为 `u32::MAX`。

存档不保存构造配置或保留数量。`restore(data)` 恢复四张表和累计起点，再应用当前保留数量；截断、未结束字串及超过读取上限的数据返回诊断，原日志保持。

## 验证范围

原入口的 2,874 组配置／文本组合逐字节核对完整序列化数据，覆盖默认／窄列、姓名同行、缩进、日文标点、括号片段和转义。另有 192 份连续生命周期快照核对两种追加、大小写不同的来源、空记录、裁剪、清空、姓名查询及 850／851 存档往返，包含完整 VM 普通区和外部区。

170 组历史导入逐字节核对序列化数据、完整 VM 两区、数值副作用和资源请求顺序，覆盖两种入口、保留窗口、空／缺失场景、原始／UTF-8 文本、语言回退、命令大小写与空格及声音标记。另有十六组两种直接追加入口的姓名分隔测试，区分 UTF-8／CP932 的全角 `＠`、`※` 和 ASCII `@`。

常规回归使用合成脚本、XML 和存档数据，覆盖分行规则、保留区／累计编号、存档恢复、跨任务持有、历史导入及状态二返回槽，不依赖游戏资源、字体或设备。尚待核实的具体行为包括全局强制换行字段的设置入口及回看窗口对象协议。
