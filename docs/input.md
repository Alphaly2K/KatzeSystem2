# 输入区域与事件接口

适配基线为 Windows CatSystem2 **2.6.1.90**。`input::Regions` 提供区域登记与属性命令，`Events` 提供逻辑坐标上的按下、释放和重复事件分派。设备采集、重复计时、指针移动通知和输入任务调度仍待接入。

## 登记与顺序

`Regions::default()` 创建空登记表。`records()` 按当前优先级返回只读记录，`get(id)` 返回排序中的首个匹配项。编号允许重复，优先级按 i32 从大到小稳定排列；相等时保持登记顺序。更改优先级会将首个匹配项移除、追加到末尾，再排序，因此即使优先级数值不变，同级位置也会改变。

命令 127 的 data1 缓冲区至少为六十字节，按小端复制十五个 DWORD。`Region::words()` 提供原始记录；其已确认字段如下：

|DWORD 索引|契约|
|--:|:--|
|0|区域编号，取自缓冲区；登记命令的 `data[0]` 不是编号|
|1|有符号优先级，登记时由 `data[0]` 覆盖|
|2|事件掩码，由命令 132 更新|
|3～6|矩形 left／top／right／bottom，保留 i32 位模式及反向边界|
|7|选择标记，登记时归零；保留非布尔值|
|8|启用值，登记时设为一；保留非布尔值|
|9|命令 136 更新的原始标记，登记时设为一|
|10|保留调用者提供的原始 DWORD，其消费语义待核实|
|11～13|位掩码存在标记／宽／高，登记时清零；原指针槽以存在标记一代替|
|14|登记时设为一；指针移动通知的门控字段，该通知尚未接入|

`id()`、`priority()`、`bounds()`、`selected()`、`enabled()` 和 `event_mask()` 查询对应字段，`hit_mask()` 返回显式位掩码。记录中的 DWORD 不作进程指针或 VM 地址解引用。区域数量超过一百万时返回诊断。

## 对象命令

`dispatch_command(command, buffers, output)` 接受 `task::Command` 和显式借用的 `CommandBuffers`，返回 true 表示命令已消费，未知编号返回 false。调用者负责对象删除门控、基类分派和输入更新；该接口尚未自动接入 `Runtime` 的输入任务。

|命令|参数与行为|
|--:|:--|
|127|`data[0]` 为优先级，data1 缓冲区为新记录；允许重复编号，追加后排序|
|128|删除编号等于 `data[1]` 的首项；忽略 `data[0]`|
|129|找到编号为 `data[0]` 的首项，将优先级改为 `data[1]`，重新追加并排序|
|130|将编号为 `data[0]` 的首项矩形改为 data1 缓冲区的前十六字节；空指针清零矩形|
|131|将编号为 `data[0]` 的首项矩形写入 data1 缓冲区的前十六字节；空指针跳过|
|132|将编号为 `data[0]` 的首项记录 DWORD 2 改为 `data[1]`|
|133|将编号为 `data[0]` 的所有匹配项的选择标记改为 `data[1]`；非零值同时清除其他编号的选择标记|
|134|把编号为 `data[0]` 的首项选择标记写入 output；找不到时保留 output|
|135／136|将编号为 `data[0]` 的首项记录 DWORD 8／9 改为 `data[1]`|

131 找不到目标时先跳过缓冲区访问。130／131 的空指针表示 data1 未提供缓冲区且 `data[1]` 为零；非零 DWORD 缺少显式缓冲区时返回诊断。提供缓冲区时 DWORD 不参与地址解释。读写只消费规定范围，其余字节保持。

130／135／136 总将 `geometry_dirty()` 置真，即使编号不存在；登记、删除、更改优先级及选择标记均不设置该标记。输入宿主完成区域重算后可调用 `clear_geometry_dirty()` 消费标记。除 134 外，上述命令均保留 output。

## 位掩码

`HitMask::new([width, height], bytes)` 接收紧密排列的位图，长度必须精确等于 `ceil(width / 8) * height`，每行独立按字节对齐，同一字节低位对应较小 X。尺寸使用非负 i32 范围，宽度加七不得溢出，字节数量受库的 64 MiB 上限约束。`contains(origin, point)` 按 i32 回绕计算相对坐标，负值、越界或未置位均不命中。

`Regions::set_hit_mask(id, mask)` 修改首个匹配项；None 清除位图及三个相关 DWORD。该显式宿主接口保持区域重算标记和 DWORD 14，尚未实现从图像 Alpha 生成位图的对象命令 147。

## 按键事件分派

`Events::default()` 提供零捕获、零全局状态及零抑制值。`KeyEvent` 包含事件类别、消息编号、0～79 的键槽、原始按下值、事件掩码及已转换的逻辑坐标。`dispatch_key(sender, regions, event, route)` 同步分派；回调接收可变区域表及 `Command`。返回 None 表示不可达，Some(0) 表示消费，其他结果表示未消费。路由错误原样返回，错误前已发生的状态修改保留。

所有消息保持传入编号，sender 为输入任务编号，target 为区域编号，data 固定为 `[key, pressed, 0]`。掩码只用于筛选及保存全局状态，不转发到第三数据项。

|事件|候选与筛选|捕获变化|
|:--|:--|:--|
|Change 且 pressed 非零|按当前顺序检查启用且掩码相交的区域；未消费时继续|开始前清零；首个消费目标成为该键捕获|
|Change 且 pressed 为零|只检查启用值；有捕获时限于相同编号，无捕获时可投递全部启用项；跳过掩码、矩形及位图|无论消费与否，正常结束时清零|
|Repeat 且 pressed 非零|有捕获时只检查首个相同编号，无捕获时只检查排序首项；使用按下筛选，失败即结束|保持原值|
|Repeat 且 pressed 为零|不投递|保持原值|

掩码含数值二时才检查空间命中：非空矩形包含左上、排除右下，空或反向矩形不限制命中；设置位图后还需相对矩形左上角的位图命中。其他事件掩码跳过全部空间检查。编号零可以消费按下事件，但捕获零仍表示无捕获。重复编号按表中规则分别参与遍历。

回调可使用区域接口追加、删除后续项或修改属性和优先级；后续遍历从当前登记项变动后的下一项继续，新插入在当前项之前的记录本次跳过。回调应在同一登记表上调用这些接口。删除或重新登记当前项后，若原入口还需访问该项，库返回明确诊断；基线在这条路径上继续访问已释放的节点。单次遍历超过一百万项也返回诊断。

`set_suppressed(value)` 非零时拒绝事件，保留捕获和全局状态。其他合法事件先保存掩码到 `raw_state()`，包括 Repeat 的释放；`state()` 提供输入命令 137 的查询映射，仅将原值十六映射为二。这里尚未自动绑定对象命令或设备更新。

## 核实范围与后续连接

80 组连续序列、3,840 次原命令调用的返回值、结果槽、完整缓冲区、重算标记和完整记录表共 1,509,720 字节全部一致。两项纯合成回归固定重复编号、有符号排序、同级重新追加、选择标记、空缓冲区、缺失目标及边界检查；常规测试无需设备或外部资料。方法见[验证记录](runtime-probes.md#输入区域登记与属性)。

事件入口的 187 组连续序列、5,781 次调用覆盖按下／释放／重复、零编号及重复编号、抑制、矩形、位图、不同路由响应和回调修改区域表。返回值、全局状态、全部捕获、4,740 条路由消息及完整区域表共 4,537,896 字节一致。四项纯合成回归固定捕获清除、单候选重复、位图布局、边界、实时游标及诊断。

平面显示命令 47／48 会查询输入命令 134，并据此处理对象状态。指针选择重算、移动通知、设备到逻辑坐标转换、输入任务封装、显示联动、图像 Alpha 到位掩码、焦点导航及平台设备继续沿相应入口接入。
