## 脚本分类

|类别|运行时输入|主要职责|解释方式|
|:--|:--|:--|:--|
|CST|`CatScene` 容器中的类型化记录|剧情、演出、消息、分支|按记录类型执行；命令记录仍需解析文本|
|CSTL|`CSTL` 多语言数据表|为消息提供姓名和正文|数据读取与消息映射，不作为命令执行|
|FES|`FES` 容器解压后的文本|界面对象、事件、流程与窗口|解析声明及可执行块，再调度对象和事件|
|ANM|`ANM` 时间线及参数表|选择 HG 图像帧并控制显示时间|执行固定指令表|
|KCS|`KCS` 容器中的编码程序体|启动、剧情执行宿主、运动和粒子逻辑|需要相应虚拟机及宿主接口|

运动脚本和部分粒子脚本使用 KCS 程序格式。原生粒子插件属于 PE DLL，与 KCS 程序分开处理。XML、CSV、DFN 是配置或数据格式；JavaScript 有独立的公开手册，当前样本未提供足以整理其实际脚本语法的输入。

CST、FES、ANM 的文本源语言与编译后的输入需要分清。例如，CST 的源标签用于产生场景文件，源宏会被展开；运行时读取的 CST 已经包含姓名、消息和输入等待等类型信息。FES 解压后仍保留声明和命令文本。ANM 则已经把标签转换为指令索引。

## 依据与状态

各文档分别列出“手册规则”“样本对照”和“待核实”内容：

- **手册规则**：官方手册明示的语言契约，或公开格式说明给出的结构。
- **样本对照**：从版本资源、归档目录及解压后的脚本批量检查所得的语法和结构事实。
- **原引擎核实**：调用基线程序的原有函数，使用合成输入或批量脚本读取核对所得的行为。
- **待核实**：资料不完整、资料与样本不同，或需要运行原引擎才能确定的行为。

数值求值、CST 命令预处理、CSTL 正文／选项映射、部分 FES 结构容错及 KCS 装载与调用已完成原引擎函数对照，范围见各页及核实记录。完整游戏主循环、事件与帧调度仍需继续验证。文中示例使用虚构资源名、标签和正文。

当前在线官方手册的更新记录止于 2016-07-08，存在早于本基线的范围限制和缺项；例如变量上限、UTF-8 对象和子命令声明。发生冲突时，文档明确记录本基线的实际用法及尚待确认的部分。FelineSystem2 用于了解实现经验和已知缺陷，其行为不作为原引擎规范。
