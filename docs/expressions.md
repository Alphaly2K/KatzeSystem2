# 词法与表达式

适用基线：CatSystem2 2.6.1.90。CST 与 FES 使用相关的数值表达式，但变量前缀、文本处理和控制流属于各自的语言。ANM 的参数引用另有定义。

## 符号所处的语境

|符号|CST|FES|ANM 源文本|
|:--|:--|:--|:--|
|`#`|源标签；命令内的数值变量前缀|块或声明头前缀|标签前缀|
|`$`|命令读取阶段转为 `0x`；此前先展开 `$str` 字符串引用|共享数值变量或 `$str` 字符串引用；颜色按命令参数解释|不在已整理的核心语法中|
|反斜杠|文本标记、源文本的特殊行写法|局部数值变量前缀；字符串内另行处理|不在已整理的核心语法中|
|`@`|目标参数的当前值|当前参数值；事件中还可表示对象或银行号|`@n` 表示动画局部变量 n 的值|
|`%`|余数运算；源宏有独立的 `%` 语法|余数、百分比参数或字符串格式项，由语境决定|不作为通用表达式运算符|

同一字节需要按语境处理。FES 将 `$12` 定义为变量引用；CST 的命令读取先把它变成 `0x12`，再交给数值入口。ANM 的 `@4` 与 FES 事件对象 `@` 也需要不同的求值入口。

## 数值与变量

官方数值说明使用有符号运算，数值变量存储为四字节整数。FelineSystem2 的浮点数符号表不作为基线的数值模型。

```ebnf
decimal       = digit, { digit } ;
hexadecimal   = "0x", hexDigit, { hexDigit } ;
cstHex        = "$", hexDigit, { hexDigit } ;
index         = decimal | "(", expression, ")" ;
cstVariable   = "#", index ;
fesGlobal     = "$", index ;
fesLocal      = "\", index ;
stringRef     = "$str", decimal ;
namedValue    = identifier, [ "[", expression, "]" ] ;
```

这里的 EBNF 使用双引号表示字面符号，反斜杠按一个实际字符读取。`cstHex` 在 CST 命令读取阶段转为 `hexadecimal`。字符串引用部分描述已核实的直接编号写法。

- CST 的 `#n` 与 FES 的 `$n` 使用共享的游戏变量区域。
- FES 的反斜杠变量属于当前脚本的局部区域。
- `#(40+#2)` 等间接引用先计算编号，再访问对应变量。
- `$str7` 是字符串替换；可出现在正文或资源参数中，不应按数值 `$` 变量读取。

旧手册给出的共享变量范围为 0～1023、FES 局部变量为 0～511。本次基线配置将共享区容量设为 **2,048 槽，即索引 0～2047**。已追踪配置读取、启动 KCS 的容量查询、数值区创建及按槽数分配四字节存储的调用链。容量来自配置，不能把旧手册的 1024 或本次的 2048 固定为所有资源的语言常量。

配置还把共享区划为两个 local 范围（0～511、1024～2047）和一个 global 范围（512～1023）。这些是共享区的保存分组，与 FES 单独的反斜杠局部存储不同；各组的完整保存、恢复和重置时机仍待存档路径核实。

原生求值器的共享变量访问和局部变量读取存在直接索引内存的路径；局部变量写入另有 512 槽检查。读取脚本时保留索引，执行时对项目自身的存储作边界检查。

赋值时需要保留独立的左值位置。例如，虚构表达式 `#4=#9+1` 的目标在求右值前已确定；右值中的变量访问不应改变赋值目标。

## 运算符集合

|类别|运算符|手册语义|
|:--|:--|:--|
|算术|`+ - * / %`|加、减、乘、除、余数|
|一元|`+ - ! ~`|保持数值、取负、逻辑非、逐位取反|
|位运算|`& ^ \| << >>`|逐位与、异或、或、移位|
|关系|`< > <= >=`|结果为 0 或 1|
|相等|`== !=`|结果为 0 或 1|
|逻辑|`&& \|\|`|按操作数是否为零产生 0 或 1|
|赋值|`= += -= *= /= %= &= \|= ^= <<= >>=`|写入左值|
|自增减|`++ --`|手册包含前置与后置写法|
|分组|`( )`|优先计算括号内的式子|

正负号作为一元或二元运算符由位置决定。一元正号保留右侧数值供外层运算读取，并执行右侧副作用；它作为整个表达式时直接返回零，不保留可写位置。例如 `+30` 返回零，`#4=+30` 写入并返回 30，`+(#4+=1)` 先递增变量再返回零。词法扫描对多字符运算符采用最长匹配，避免将 `>>=` 拆成 `>>` 和 `=`。

表达式的结构可以先描述为：

```ebnf
expression    = unary, { binaryOperator, unary } ;
unary         = { unaryOperator }, primary, [ postfixOperator ] ;
primary       = number | variable | currentValue
              | "(", expression, ")" ;
assignment    = lvalue, assignmentOperator, expression ;
```

FES 还允许命令所声明的系统值和对象名作为操作数。标识符以 ASCII 字母或下划线开头，随后可含数字；名称区分大小写。`name` 读取银行 0，`name[expression]` 先计算银行号再查表，缺失项返回零。命名值在遍历该节点时取得数值，不保留共享变量那样的可写位置。宏在 FES 行级预处理时展开，再进入数值入口。

命名值由宿主注册，包含系统状态或对象标识；每个 FES 有自己的绑定表。命名值作为赋值、自增减目标时，原入口返回零且绑定保持原值，库返回左值诊断。空银行索引会使原入口访问无效内存，库在解析时返回诊断。点号属性、圆括号调用和多重索引尚未形成库接口，不按命名值语法接受。

392 组合成表达式已对照原入口，覆盖名称大小写、系统名称、默认／负数／整数边界银行、索引副作用和节点取值时机，结果与变量副作用全部一致。

## 优先级和求值规则

下表来自基线原生数值解析器的优先级表，并用合成表达式实际调用核对。FES 和 CST 的 KCS 宿主数值接口均调用该内核；CST 在求值前另有下面的命令预处理。

|优先级：高到低|运算符|结合方向|
|:--|:--|:--|
|分组／索引|`( )`、变量前缀与索引|按结构处理|
|自增减|`++ --`|前置／后置|
|一元|`+ - ! ~`|作用于右侧操作数|
|乘除余|`* / %`|左结合|
|加减|`+ -`|左结合|
|移位|`<< >>`|左结合|
|关系|`< <= > >=`|左结合|
|相等|`== !=`|左结合|
|逐位与|`&`|左结合|
|逐位异或|`^`|左结合|
|逐位或|`\|`|左结合|
|逻辑与|`&&`|左结合|
|逻辑或|`\|\|`|左结合|
|赋值|`= += -= *= /= %= &= \|= ^= <<= >>=`|右结合|

关系层位于移位与相等之间。手册优先级表中重复的 `<<= >>=` 不采用为关系层定义。

原生求值器已确认以下行为，合成对照用例见[原引擎核实记录](runtime-probes.md)：

- **零为假、非零为真**；比较、逻辑与和逻辑或返回 0 或 1。
- **逻辑运算不短路**。`0&&(++#4)` 和 `1||(++#4)` 都会修改变量。
- 前置和后置自增减均返回更新后的值。初值为 10 时，`#4++` 返回 11，变量也变为 11。
- 加、减、乘与取负按 32 位回绕；十进制和 `0x` 整数字面量也保留低 32 位。
- 有符号除法向零截断，余数与被除数同号。普通 `/0` 和 `%0` 返回 0；`/=0`、`%=0` 触发整数除法异常。`INT_MIN/-1` 同样触发异常。
- 右移为算术右移；移位数取低 5 位，所以 `1<<32` 为 1，`1<<-1` 与 `1<<31` 相同。
- 赋值保留左值索引，链式赋值从右向左完成。右侧变量引用不会覆盖赋值目标。
- 二元子树先求左侧、再求右侧；变量引用可保留到运算时才取值。初值 `#4=1` 时，`#4+(#4=5)` 返回 10，而 `(#4=2)+(#4=3)` 返回 5。

最后一项要求区分变量位置和值：不能在遍历到所有变量节点时一律立即复制其数值。非法索引的直接内存访问应在本项目中转为脚本诊断。

FES 原求值器对 `+3` 和 `(+3)` 返回零，`3`、`0+3` 和 `1+3` 分别返回 3、3 和 4；一元 `+` 不作为合法取值运算符处理。本库对这两种一元加号输入保留语法诊断。连续无括号后置表达式及其他非法输入的恢复仍待核实。

## CST 的预处理与数值入口

已执行基线剧情 KCS 的原命令读取函数，并保留原字符串替换、参数提取和数值宿主函数，确认以下顺序：

1. 读取当前类型化记录。
2. 展开 `$strN`。
3. 对 Command 记录，将剩余 `$` 全部替换为 `0x`。
4. 提取命令参数，再交给数值求值器。

例如，合成命令参数 `$100` 进入求值器前为 `0x100`，结果为 256。若字符串变量 7 的值为 `$100`，命令中的 `$str7` 也先展开、再变成 `0x100`。Message 和 Name 走文本读取分支，不执行这一步十六进制替换。

直接调用原数值入口时，`$100` 与 `#100` 均引用共享变量 100；这是预处理后的内部入口规则。FES 使用这个变量语义。CST 解释器应保留记录类型与处理顺序，不能在数值词法器中统一把 `$` 当十六进制。

KCS 的数值宿主函数还会在求值前去掉参数末尾的一个 `%`：`50%` 返回 50，`50%3` 返回 2。空参数及去掉百分号后为空的参数返回零，保留变量与当前值。百分比的比例换算由具体命令负责。该入口的处理不应自动扩展到 FES 的全部表达式。

## 参数边界与文本边界

- 基线剧情 KCS 的通用参数入口以半角空格分隔。合成输入中的 Tab 被保留在参数内；源文本编译阶段如何处理 Tab 仍需单独核实。
- 不带分组的运算符不会把多个参数重新组合，例如 `pos 50 % 3` 为四个词项（含命令名）。圆括号分组中的空格会保留，`probe (1 + 2) 7` 的参数是 `(1 + 2)` 和 `7`。
- `(:hello world)` 在该入口中作为一个文本参数，返回 `hello world`，去掉外层 `(:` 与 `)`。
- 赋值语句的右侧以及 `if (...)` 的条件有独立的表达式边界，可包含空白。
- 通过括号深度确定 `if` 条件的结束位置，随后再解析该语言支持的语句形态。
- 引号内的字符串、逗号形式的资源参数、数组／银行选择器和百分比参数需要由相应命令或声明语法读取。
- 转义引号、未闭合分组及各命令额外分隔规则仍待核实。

CP932 的双字节字符可含 `0x5C` 尾字节。识别文本转义时必须识别字符边界；FES 的不同编码文本路径还需要保留原始字节。不要直接对原始字节进行通用反斜杠替换。

## FES 整行回退

以 `$` 或反斜杠开头的独立数值语句也使用整行求值规则。只读目标赋值会执行左右子表达式并产生零，因此 `\130 = 131 = -1` 将局部槽 130 写为零并继续运行。严格的独立表达式 API 仍拒绝只读目标写入。

运行时在对象名称或起始银行不存在时，以行级展开后的完整命令进入数值回退；先前用于查找对象的银行表达式已经执行。普通属性、动画、默认运动、绘制、停止、焦点通知及已注册子命令共用该规则。回退在任何对象修改、资源补全或子命令参数映射之前执行，完成后继续脚本。

该入口接受连续操作数，以操作数栈和运算符栈构树，最后只执行栈顶结果。`missing pos ($0+=1) ($1+=2)` 只递增第二个变量；`missing[($0+=1)]` 的银行表达式会在整行结果中再次执行。额外词项可能改变最终结果树，不能按对象命令的参数数量截断。括号不清空已有操作数；例如 `1+(2 3)` 的结果为五。

整数和变量沿用上述求值规则，两个逻辑操作数均求值。字符串字面量的数值为零。只读名称或常量作为赋值、自增减目标时，子表达式副作用保留，操作结果为零。原始 `$0++` 按前置形式返回新值，`($0)++` 返回旧值。单目正号执行其子表达式并返回零；按位取反在此入口保留原优先级，`~1+2` 为负四。逗号、句点和问号／冒号形成的未支持运算结果为零，其子树不执行。

命令目标为 `@` 且没有事件上下文时，同样进入数值回退，使用宿主当前值。回退使用所属 FES 的局部值、命名值及事件银行，完成或失败后恢复宿主作用域。长度上限为 64 KiB，词项上限为 512；括号错误、未接入词项和未支持的索引目标返回诊断，解析失败不产生数值副作用。`expression::eval` 等严格接口继续要求完整消费单个表达式，未消费后缀返回位置诊断。

519 组原表达式树的结果和全部观测变量与回退入口一致。另有 178 组完整对象调用在两种预算下匹配。常规回归使用内存构造的脚本，覆盖树选择、只读写入、三种执行作用域、子命令原始行和资源服务旁路。

## 样本对照

- 38,739 条 CST 条件的括号边界可定位，条件内容被上述数值词法集合完整消费。
- CST 实际出现十六进制、逻辑非、间接变量、`@` 和字符串替换；银行区间和枚举也有使用。
- FES 实际出现比较、逻辑、自增减和复合赋值，以及共享／局部变量和对象操作数。
- 条件语料的检查覆盖词法和括号；上述求值规则另由原生数值入口的合成运行及优先级表核对确定。

独立检查 FelineSystem2 时，已复现其读取右值后写错左值，以及把不支持的字符当作表达式结束的问题。解释器的诊断应能指出未消费的后缀和原始位置。
