# 图形标记配置与查询

适用基线：CatSystem2 2.6.1.90。普通 1055～1061 共同使用任务独立的 `emocon` 配置，提供标记名称、标签、位置、缩放和纹理名称。任务释放时清理状态。

## 配置装载

1055 以散装优先模式读取固定资源 `config.int/emodef.xml`，按既有 XML 契约解析。每次调用先清空尺寸、角色及标记三张表；缺失或无效 XML 保留旧的全局纹理缩放和停止标签。有效 XML 重新读取这两个字段，并按连续编号枚举条目，遇到缺失的终止字段后停止。

|路径|字段及默认值|枚举终点|
|:--|:--|:--|
|`size/s01`、`s02`…|`id` 一百、`scale` 一百；`prefix` 判断条目是否存在|缺失 `prefix`|
|`size/texscale`|全局纹理缩放，一百|单值|
|`ch/c01`、`c02`…|角色 `id`|`id` 为 0xffffffff|
|各角色下 `p01`、`p02`…|姿势 `id`、`table` 配置文件名|`id` 为 0xffffffff|
|`emocon/stop/label`|停止标签，空文本|单值|
|`emocon/em01`、`em02`…|标记 `id`、`name`、`label`；`pos/x`、`pos/y` 各一百；`scale` 负一；`tex/half` 零；`tex/l`、`tex/s` 空文本|`id` 为 0xffffffff|

姿势的 `table` 存在时读取 `config.int/` 加文件名的 XML，再按根层 `em01`、`em02`…枚举偏移记录；`id` 为 0xffffffff 时结束，`offset/x`、`offset/y` 默认零。缺失表保留该姿势的空记录集。重复角色、姿势、标记或尺寸编号均按保存顺序取首个命中；名称匹配区分大小写。

## 普通脚本接口

|编号|参数|行为|
|:--|:--|:--|
|1055|忽略|重装载当前任务的配置，状态二|
|1056|名称格式地址、尺寸 ID、基础 X、基础 Y、输出 X 地址、输出 Y 地址、输出缩放地址、输出纹理名地址|查询并换算位置、缩放及纹理名称，状态二|
|1057|忽略|以状态一返回标记数量|
|1058|零起始下标、输出地址|查询 name，状态二|
|1059|零起始下标、输出地址|查询 label，状态二|
|1060|输出地址|查询停止标签，状态二|
|1061|角色 ID、姿势 ID、标记 ID、输出 X 地址、输出 Y 地址|查询姿势表的原始偏移，状态二|

状态二保留 native 返回槽。字符串输入在 KCS 格式展开和首零截断后按 CP932 解码，输出也为 CP932；无可编码字符时返回诊断。1058／1059 越界输出空字符串；1058～1060 的输出起点无效时跳过写入。输出地址零有效，两个 VM 区均可写。

1056 先将输出 X、Y 清零。尺寸 ID 和 name 都命中时，位置分别为 `(标记位置 + 基础位置) × 尺寸缩放 / 100`，纹理缩放为 `(全局纹理缩放 × 尺寸缩放 / 100) × 标记缩放 / 100`。乘法和加法使用带符号 DWORD 回绕，除法向零截断。缩放小于五十且 `half` 非零时选择 `tex/s`，输出缩放再乘二；其余选择 `tex/l`。查询失败时纹理名输出 `dummy`，缩放输出保持原字节。

1061 先将两个输出清零，依角色、姿势和标记 ID 查找；命中后依次写入原始 X、Y 偏移，不应用表内缩放。无效数值输出地址返回受检诊断。

## 验证

1,036 份原入口快照核对七个接口的返回值和完整 VM 两区，覆盖重装载失败后的状态、默认字段、编号缺口、重复名称、负数／整数回绕、小纹理切换及姿势偏移；配置资源请求顺序也一致。常规回归使用合成 XML 和脚本，固定两个执行预算、任务隔离、返回槽、跨区输出和任务释放后的状态清理，无外部资源或设备依赖。
