# 电影

`movie::Decoder::new(SharedSource)` 创建独占流式解码器，输入为 MPEG Program Stream，视频为 MPEG-1，音频为可选 MP2／MP3。资源服务、归档和文件均通过同一随机读取接口提供字节。创建会探测首个 MiB 的实际 PES 流；音轨不依赖系统头的 audio_bound 声明。

`metadata()` 返回尺寸、帧率、音频采样率和容器视频时长。当前视频要求非零偶数宽高，输出面受图形像素容量上限约束，输入长度不超过有符号 32 位位置范围。采样率为零表示没有音轨。容器视频时长可能早于音频或最后一幅画面的结束，播放完成应使用 `Decoded::ended`。

`advance(seconds)` 同时消费视频和音频，单次间隔为零至一秒。它返回本次最后一幅视频帧及全部连续音频；没有新画面时，调用方继续保留上一幅。画面为顶端起始、不透明 BGRA，音频为标准化 f32 交错立体声。输出由调用方持有，后续解码不会修改已返回的数据。

时间从流起点按视频帧率和音频采样率计算；当前不使用逐包 PTS 修正两条流的偏移。`time()` 查询累计推进时刻，结束状态以解码耗尽为准。解码器可以移动到工作线程；推进调用同步读取来源，宿主应将其放在设备音频回调以外执行。

读取失败、提前结束、违反读取量约定及回调 panic 返回诊断，不跨越 C ABI 展开。发生解码或读取错误后丢弃实例。大幅时钟跳跃由调用方分批推进。

## 播放与输出

`Player::new(source)` 探测媒体，`play(count)` 在后台解码；返回前预取少量输出。零和 `u32::MAX` 无限循环，其他值为完整播放次数。正在播放时再次启动返回 false；完成或停止后可以重播。`stop()` 清除待消费输出、唤醒并回收线程，返回停止前的播放状态。`is_playing()` 同时报告后台读取或解码错误。

`audio_output()` 提供单个音频消费端；通过 `SoundState::set_movie_output` 接入声音状态或已连接的 `Mixer`，不占六十四个脚本声音通道。设备混音不等待文件或解码，暂缺输出时保留电影消费位置。直接调用 `SoundState::mix_stereo` 的离线混音等待所需数据。有音轨时以实际采样消费为时钟；无音轨时由宿主调用 `advance(seconds)`。`set_volume` 接受 0～100，静音仍推进播放。

多播放器使用 `SoundState::set_movie_track(handle, output)` 登记独立音轨，传入 None 移除该句柄；零号保留给 `set_movie_output`。替换或移除一条音轨保留其他音轨与普通声音通道。连接独立 `Mixer` 前后的登记都有效，各播放器按自身实际消费的采样推进时钟。

`take_video()` 返回当前时刻可显示的最后一幅新画面；宿主持有前次画面直到更新。播放器只保留有界的预取画面与音频，不保存整部电影。视频不随窗口刷新次数加速，渲染和音频可分别消费。

## 运行时入口

Runtime 通过普通 265 装载一个独占电影句柄，名称使用格式展开和 `movie` 类别补全，再经 `ResourceServices::open` 读取。`etc_disablemovie` 非零时返回零；找不到来源时返回零并恢复游戏绘图。装载下一部独占电影前须释放现有句柄；平面电影可并行持有。

|编号|参数|结果与行为|
|:--|:--|:--|
|265|名称格式地址|电影句柄或零；成功后进入电影显示|
|266|句柄、次数|启动成功返回一，零句柄或已在播放返回零|
|267|句柄|停止前仍在播放返回一，否则零|
|268|句柄|停止释放并恢复游戏绘图，非零句柄返回一，零返回零|
|269|句柄|返回活动状态，零句柄返回零|
|270|句柄|沿当前宿主窗口显示，保留返回槽|
|417|句柄、音量|应用旧声音配置的背景音量与静音开关，保留返回槽|
|788|句柄、x、y、宽、高|设置影片显示矩形，保留返回槽|
|996|句柄、可见标志|零隐藏电影画面，非零恢复，播放和混音持续；零句柄跳过，保留返回槽|
|997|句柄、普通绘图开关|非零显示游戏，零显示电影；保留返回槽|
|998|句柄|视频时长毫秒值，零句柄返回零|

电影画面作为共享图像纹理提交至现有绘制列表，软件帧与窗口后端共用来源；默认铺满逻辑画面，显式矩形以外为黑色。隐藏独占电影时保留黑色画布，游戏绘图仍由 997 控制。隐藏平面电影时只移除该平面的电影纹理。深度区间捕获继续读取游戏图元。无音轨电影使用 `HostState::system_time_ms`，预算续跑中的同一时刻不重复推进。

## 平面电影装载

普通 701 接受目标任务和名称格式地址，按 `movie` 类别补全名称，再向目标发送命令 43；目标为零时直接返回。命令记录为三个 f32 坐标及紧随其后的 NUL 结尾名称。PLANE 先释放旧图元，仅在创建标志为一且 `Host::movie_enabled()` 为真时打开来源；成功后形状类型为三，偏移为零，尺寸取电影边界。替换图元和任务回收均释放来源。

普通 988 使用同一记录协议，按 `veff` 类别补全并发送命令 44；创建标志仍须为一，形状类型为四，不受 `movie_enabled()` 控制。

装载时保留游戏绘图，电影保持停止；未取得画面前不提交纹理，也不连接声音输出。普通 654 展开两个字符串并发送命令 85，目标为零时仍执行展开与分发；PLANE 的命令 85／86 均为空操作。701／988／654 均保留 native 返回槽。

普通 702／989 分别通过命令 87／88 查询平面的普通电影／视频特效句柄，未装载或来源不匹配时返回零；零目标仍执行分发。返回的句柄可用于 266／267／269／417／996／998 等播放器入口。播放器由运行时持有，平面通过宿主的装载、查询、释放服务绑定，资源打开仍使用该平面当前的资源服务。

266 启动后，画面更新独立图像纹理，沿平面的变换、相机、排序、裁剪与混合路径提交；首次启动前、未取得首帧及资源释放后均不提交。停止保留已显示画面，重播重新取得首帧。有音轨时登记到可达的声音任务，其他影片与普通声音继续消费。平面替换、删除及任务回收停止并移除对应音轨与播放器，后续查询返回零。当前两类来源共用上述 MPEG 解码格式。
