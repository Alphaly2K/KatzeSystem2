# ANM 帧动画

适用基线：CatSystem2 2.6.1.90。ANM 选择 HG 图像的帧 ID 并控制时间线，变量与跳转规则独立于 CST、FES。

## 源语法

```ebnf
animation = { label | instruction } ;
label     = "#", labelName ;
operand   = integer | "@", variableIndex | labelName ;
```

源文件由 `ac.exe` 编译，标签转换为后继指令的索引。动画有 64 个局部整数变量，编号 0～63。普通数值位置使用 `@n` 时读取变量 n；要求变量编号的参数默认直接使用编号。

结构示例：

```text
#cycle
set 0 2
#repeat
0 6
1 9 12
loop 0 repeat
jump cycle
```

这一示例使用虚构帧 ID。显示命令的 ID 是图像内的帧标识，不能直接当作解码后帧数组的下标。

**本基线的 `loop` 与官方手册不同：变量大于零时减一并顺序执行；变量为零或负值时跳转，变量保持不变。** 该行为已通过原执行器和合成指令核实，当前实现遵循 2.6.1.90。官方手册描述为正值时减一并跳转，当前分支不采用该描述。

## 指令表

方括号参数必需，圆括号参数可省略。指令编号最初来自公开资料，本基线的 0～17 已对照原执行器。实际动画资源只覆盖 ID 0 和 3，其余使用合成指令核实。

|ID|源写法|语义／状态|
|:--|:--|:--|
|0|`imageId min (max)`|选择帧，持续给定范围的时间|
|1|`set var min (max)`|向变量写入值或范围内随机值|
|2|`loop var label`|变量大于零时减一并继续，否则跳转|
|3|`jump label`|无条件跳转|
|4|`if value label`|参数值大于零时跳转|
|5|`ife left right label`|相等时跳转|
|6|`ifn left right label`|不等时跳转|
|7|`ifg left right label`|大于时跳转|
|8|`ifs left right label`|小于时跳转|
|9|`ifge left right label`|大于等于时跳转|
|10|`ifse left right label`|小于等于时跳转|
|11|`max var`|将宿主提供的最大图像帧 ID 写入变量|
|12|`blend value`|保存原始混合值，默认 255，不在指令层截断|
|13|`disp value`|保存原始显示值，默认 1，不在指令层转为布尔值|
|14|`pos x y`|保存原始 x／y，默认均为 0；与图像绘制基点的组合由宿主处理|
|15|`wait min (max)`|保持当前帧并等待|
|16|`add var value`|变量加法|
|17|`sub var value`|变量减法|

可选 max 未写时，编译器将其写为与 min 相同的值。两端相等时直接使用该值，不消耗随机数；其他情况采用 `min + random_u32 % (max - min)`，减法与加法按 32 位回绕。因此正常范围左闭右开，反序端点不交换，而按回绕后的无符号跨度计算。原执行器使用宿主的共享随机源。

二进制条件指令 4～10 比较解析后的参数值，不隐式把第一个参数当成变量编号。访问变量必须使用参数类型 1；比较使用有符号 32 位值。指令 1、2、11、16、17 的第一个解析值才作为目标变量编号。

## 二进制结构

所有整数为小端。文件头为 32 字节，后接定长指令。

|偏移|类型|字段|
|:--|:--|:--|
|`0x00`|4 字节|签名 `ANM` 加零字节|
|`0x04`|u32|未明字段|
|`0x08`|u32|指令数 N|
|`0x0C`|20 字节|未明区域，本次样本为零|
|`0x20`|`N × 68` 字节|时间线指令|

一条指令为 u32 指令 ID，加 8 组参数；每组参数为 u32 参数类型及 u32 原始值。

|参数类型|解释|
|:--|:--|
|0|字面值；标签在编译后通常也使用此类型|
|1|变量值引用|
|2|标签形式，公开资料称执行时按字面值解释；本次未出现|

参数槽数固定为 8，具体指令只取需要的参数。文件内的 u32 原始值与执行时整数的符号解释需要区分。

## 执行边界

源手册用帧数描述显示时间。局部变量、指令位置、当前图像帧及剩余显示时间构成动画自身状态；场景变量或 FES 局部变量不能替代动画变量。

跳转和变量操作可能在到达下一条计时指令前连续执行。没有时间消耗的循环需要能定位，不应持续占住宿主事件循环。动画结束、隐藏、重载、暂停和快进时的状态处理尚待动态核实。

## 样本对照

3 份 ANM 全部满足 `文件长度 = 32 + N×68`，共有 24 条指令，均为帧选择和跳转，参数类型均为 0。其帧选择和跳转参数位置与公开格式一致。

已对全部 18 种指令及参数类型 0／1／2 运行原执行器核对。122 个合成用例覆盖指令位置、时间、变量、显示状态、随机调用数及循环／条件边界，与 Rust 执行器全部一致。时钟缩放和时间追赶另以 2,340 组合成更新及三份实际动画的 108 次更新核对，显示状态、变量、游标、持续时间、时间基点及随机调用数全部一致。暂停、重载和对象层显示属性组合继续接入。

库通过 `run_with_random` 接收宿主随机源；固定区间可直接使用 `run`。`display` 提供当前帧、混合、显隐和位置，属性指令连续执行到下一个计时事件；`max_image_id` 由加载图像的宿主提供。负持续时间返回诊断，宿主完成正持续时间或零时长事件后再推进。

## 时间调度

`Timeline` 包含指令解释器、速度、时间基点及当前持续时间。`update(now, budget)` 返回本轮是否完成，`false` 表示预算让出；调用者读取 `interpreter.display`，用 `display_changed()` 判断本轮最终显示状态是否变化。`is_finished()` 在最后一项持续时间结束且指令游标到达末尾后返回 true。需要随机区间时使用 `update_with_random`，继续共享宿主随机序列。

每轮先对 `now − origin` 做 u32 回绕，再解释为 i32，转为 f32 并乘速度，向零截断为 i32。越界、NaN 或无穷转换为 i32 最小值。换算结果小于当前持续时间时保持状态；否则连续执行指令，追赶到下一处未完成的等待或程序末尾。

每遇到帧选择或等待，先从本轮剩余时间减去上一项持续时间，同时给 origin 加上该持续时间，再保存新持续时间。origin 的累加使用未缩放的原始整数，各整数运算按 32 位回绕。速度不等于 1 时，即使 now 相同，后续更新也可能继续推进。零和负持续时间保留原值，按同一有符号比较决定是否继续追赶。

预算续跑保留已换算的剩余时间和本轮开始时的显示快照，不重新使用传入的 now。没有时间消耗的循环受预算约束。`display_changed()` 比较整轮开始与结束时的五项属性；中途改变后恢复原值时返回 false。对象层的属性组合、暂停与重载由外层任务负责。
