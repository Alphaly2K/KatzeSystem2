# ANM 帧动画

适用基线：CatSystem2 2.6.1.90。ANM 选择 HG 图像的帧 ID 并控制时间线，变量与跳转规则独立于 CST、FES。

## 源语法

```ebnf
animation = { label | instruction } ;
label     = "#", labelName ;
operand   = integer | "@", variableIndex | labelName ;
```

源文件由 `ac.exe` 编译，标签转换为后继指令的索引。动画有 64 个局部整数变量，编号 0～63。普通数值位置使用 `@n` 时读取变量 n；要求变量编号的参数默认直接使用编号。

结构示例：

```text
#cycle
set 0 2
#repeat
0 6
1 9 12
loop 0 repeat
jump cycle
```

这一示例使用虚构帧 ID。显示命令的 ID 是图像内的帧标识，不能直接当作解码后帧数组的下标。

**本基线的 `loop` 与官方手册不同：变量大于零时减一并顺序执行；变量为零或负值时跳转，变量保持不变。** 该行为已通过原执行器和合成指令核实，当前实现遵循 2.6.1.90。官方手册描述为正值时减一并跳转，当前分支不采用该描述。

## 指令表

方括号参数必需，圆括号参数可省略。指令编号最初来自公开资料，本基线的 0～17 已对照原执行器。实际动画资源只覆盖 ID 0 和 3，其余使用合成指令核实。

|ID|源写法|语义／状态|
|:--|:--|:--|
|0|`imageId min (max)`|选择帧，持续给定范围的时间|
|1|`set var min (max)`|向变量写入值或范围内随机值|
|2|`loop var label`|变量大于零时减一并继续，否则跳转|
|3|`jump label`|无条件跳转|
|4|`if value label`|参数值大于零时跳转|
|5|`ife left right label`|相等时跳转|
|6|`ifn left right label`|不等时跳转|
|7|`ifg left right label`|大于时跳转|
|8|`ifs left right label`|小于时跳转|
|9|`ifge left right label`|大于等于时跳转|
|10|`ifse left right label`|小于等于时跳转|
|11|`max var`|将宿主提供的最大图像帧 ID 写入变量|
|12|`blend value`|保存原始混合值，默认 255，不在指令层截断|
|13|`disp value`|保存原始显示值，默认 1，不在指令层转为布尔值|
|14|`pos x y`|保存原始 x／y，默认均为 0；与图像绘制基点的组合由宿主处理|
|15|`wait min (max)`|保持当前帧并等待|
|16|`add var value`|变量加法|
|17|`sub var value`|变量减法|

可选 max 未写时，编译器将其写为与 min 相同的值。两端相等时直接使用该值，不消耗随机数；其他情况采用 `min + random_u32 % (max - min)`，减法与加法按 32 位回绕。因此正常范围左闭右开，反序端点不交换，而按回绕后的无符号跨度计算。原执行器使用宿主的共享随机源。

二进制条件指令 4～10 比较解析后的参数值，不隐式把第一个参数当成变量编号。访问变量必须使用参数类型 1；比较使用有符号 32 位值。指令 1、2、11、16、17 的第一个解析值才作为目标变量编号。

## 二进制结构

所有整数为小端。文件头为 32 字节，后接定长指令。N 必须非零，输入至少包含 `32 + N×68` 字节；声明指令区之后的附加字节被忽略。

|偏移|类型|字段|
|:--|:--|:--|
|`0x00`|4 字节|签名 `ANM` 加零字节|
|`0x04`|u32|未明字段|
|`0x08`|u32|指令数 N|
|`0x0C`|20 字节|未明区域，本次样本为零|
|`0x20`|`N × 68` 字节|时间线指令|

一条指令为 u32 指令 ID，加 8 组参数；每组参数为 u32 参数类型及 u32 原始值。

|参数类型|解释|
|:--|:--|
|0|字面值；标签在编译后通常也使用此类型|
|1|变量值引用|
|2|标签形式；原执行器按字面值解释，已用合成指令核对，实际资源未出现|

参数槽数固定为 8，具体指令只取需要的参数。文件内的 u32 原始值与执行时整数的符号解释需要区分。

## 执行边界

源手册用帧数描述显示时间。局部变量、指令位置、当前图像帧及剩余显示时间构成动画自身状态；场景变量或 FES 局部变量不能替代动画变量。

跳转和变量操作可能在到达下一条计时指令前连续执行。没有时间消耗的循环需要能定位，不应持续占住宿主事件循环。动画结束、对象层停更／恢复及 ANM 字节重载已核实；资源名称请求和主循环快进时的调度继续接入。

## 样本对照

3 份 ANM 全部满足 `文件长度 = 32 + N×68`，共有 24 条指令，均为帧选择和跳转，参数类型均为 0。其帧选择和跳转参数位置与公开格式一致。

已对全部 18 种指令及参数类型 0／1／2 运行原执行器核对。122 个合成用例覆盖指令位置、时间、变量、显示状态、随机调用数及循环／条件边界，与 Rust 执行器全部一致。时钟缩放和时间追赶另以 2,340 组合成更新及三份实际动画的 108 次更新核对，显示状态、变量、游标、持续时间、时间基点及随机调用数全部一致。对象层播放开关另以 1,560 次更新、属性组合以 2,048 组查询核对，结果全部一致；装载及更换的 420 份状态快照也全部一致。

库通过 `run_with_random` 接收宿主随机源；固定区间可直接使用 `run`。`display` 提供当前帧、混合、显隐和位置，属性指令连续执行到下一个计时事件；`max_image_id` 由加载图像的宿主提供。持续时间保留有符号值，时钟调度使用同一有符号比较处理零和负持续时间。

## 时间调度

`Timeline` 包含指令解释器、速度、时间基点及当前持续时间。`update(now, budget)` 返回本轮是否完成，`false` 表示预算让出；调用者读取 `interpreter.display`，用 `display_changed()` 判断本轮最终显示状态是否变化。`is_finished()` 在最后一项持续时间结束且指令游标到达末尾后返回 true。需要随机区间时使用 `update_with_random`，继续共享宿主随机序列。

每轮先对 `now − origin` 做 u32 回绕，再解释为 i32，转为 f32 并乘速度，向零截断为 i32。越界、NaN 或无穷转换为 i32 最小值。换算结果小于当前持续时间时保持状态；否则连续执行指令，追赶到下一处未完成的等待或程序末尾。

每遇到帧选择或等待，先从本轮剩余时间减去上一项持续时间，同时给 origin 加上该持续时间，再保存新持续时间。origin 的累加使用未缩放的原始整数，各整数运算按 32 位回绕。速度不等于 1 时，即使 now 相同，后续更新也可能继续推进。零和负持续时间保留原值，按同一有符号比较决定是否继续追赶。

预算续跑保留已换算的剩余时间和本轮开始时的显示快照，不重新使用传入的 now。没有时间消耗的循环受预算约束。`display_changed()` 比较整轮开始与结束时的五项属性；中途改变后恢复原值时返回 false。对象层控制更新，`ImageAnimation` 提供字节装载与显示缓存。

对象更新使用 `update_frame` 或 `update_frame_with_random`：now 为 `u32::MAX` 时，以当前 origin 作为本次时刻；origin 为零时，先设为本次时刻，再推进。零时刻仍保留零基点，下一次对象更新会重新设定基点。此封装与原始 `update` 分别对应对象时钟和已确定基点的指令时钟。

`restart()` 清除本轮预算状态，重新从第一条指令执行，持续时间归零，五项显示属性恢复默认；变量、最大帧 ID、速度及 origin 保留。原对象时钟与重启入口另以 2,340 次合成调用核对，覆盖零起点、时间哨兵、多次重启和变量保留，全部状态一致。播放开关的时钟行为见下节。

## 对象播放与属性组合

图像对象的播放开关关闭时不调用时间线更新，保留指令、显示和时间基点。重新打开开关也不修改基点，因此下一次更新按持续增长的时钟追赶。宿主可直接控制是否调用 `update_frame`；不要为停更时间平移 origin。首次更新标记独立于播放开关：存在该标记时，第一次实际更新先把 origin 设为当前 now，再清除标记。关闭开关期间保留这一标记。

对象只在本轮五项动画显示值变化时复制显示快照并请求切换图像帧。时间和指令可以推进而不产生帧切换；属性改变而帧 ID 相同时仍会请求相同帧。保持图像缓存时，应在整轮完成并且 `display_changed()` 为 true 后读取 `interpreter.display`。

`DisplayState::compose(position, blend, visible)` 将动画快照与图像自身属性组合，返回值保留动画帧 ID。坐标先把图像的 f32 坐标向零截断为 i32，非有限数或越界使用 i32 最小值，再按 32 位回绕加入动画偏移。混合值先取两个原始整数的低 32 位乘积；将乘积解释为 u32，小于 `0xff00` 时除以 255，否则取 255。图像显隐为零时结果为零，否则使用动画原始显隐值。未绑定动画时直接使用图像自身属性，无需调用组合接口。

原对象更新入口的 1,560 次合成调用覆盖停更、恢复、首次时间重设、零时刻、非单位速度及时间哨兵，时间线、显示缓存和帧切换记录全部一致。另以 2,048 组原属性查询核对正负整数、回绕乘积、非有限坐标及未绑定动画路径，全部结果一致。图像资源装载、父子传播和实际绘制继续接入。

## 图像对象的动画装载

`ImageAnimation::load(bytes, max_image_id)` 接收已经读取的 ANM 字节及图像宿主提供的最大帧 ID。它先移除旧时间线，再解析新输入；失败时保持无动画，不继续旧程序。成功时建立全新的时间线：变量、origin 和持续时间归零，速度恢复 1.0，显示缓存恢复默认。最大帧 ID 的选择使用图像帧标识的无符号最大值，再保留其 i32 位模式；没有图像帧时传零。这里与保留变量、速度和 origin 的 `Timeline::restart()` 分开使用。

对象控制字段 `playing`、`reset_time_on_update` 和 `time` 跨装载保持。`playing` 默认零，非零允许开始下一轮更新；首次更新时间重设标记仅在实际推进时消耗。`time` 保存该标记最后应用的原始 now，之后的时间线追赶只调整 origin。

`update(now, budget, has_reset_frame)` 返回本轮是否完成，`update_with_random` 另接共享随机源。只有完成的更新发生显示变化时，`frame_change()` 才返回需要宿主选择的帧 ID；预算让出和未变化时返回 `None`。预算续跑完成已经开始的同一轮，并保留该轮时间、是否请求保留帧及随机副作用；新的播放开关值在下一轮生效。

`ImageAnimation::restart(budget, has_reset_frame)` 对应图像对象的重启动作：先重启现有时间线，再强制使用 `u32::MAX` 时刻推进一次，最后恢复原播放开关。暂停时同样执行这次更新，首次时间重设标记也可能在此消耗。`restart_with_random` 另接共享随机源。返回 false 时用普通 `update`／`update_with_random` 继续该轮；再次调用 restart 会开始新的重启动作。没有动画时不产生选帧请求。与此相比，`Timeline::restart()` 只复位执行状态，不立即推进。

`display()` 返回对象的动画显示缓存，变量及运行状态可通过 `timeline` 访问。装载失败后缓存保留旧值，此时 `timeline` 为 `None`，宿主使用图像自身属性。装载成功后尚未更新时缓存为默认状态。对象只在整轮结束且显示变化时刷新缓存；随后可用 `DisplayState::compose` 组合图像属性。

当原始 now 为 `u32::MAX`、图像包含帧 ID 10000 且本轮显示变化时，缓存及选帧请求使用 10000；时间线内部仍保留脚本产生的帧 ID。宿主通过 `has_reset_frame` 提供这一帧是否存在。普通更新不作此替换。实际图像选帧、帧资源生命期及图形提交继续由图像宿主负责。

原图像装载、替换和更新入口的 60 组合成场景共 420 份快照，覆盖有无帧表、无符号最大帧 ID、保留帧、播放状态、首次时间标记、失败替换、截断输入和尾部字节。加载结果、时间线、变量、显示缓存及选帧调用全部与库一致。

同批场景另增加图像重启及后续更新的 120 份快照，覆盖暂停和首次时间标记，全部状态一致。常规合成回归同时检查强制更新的预算续跑、原播放值恢复、变量保留及共享随机数只消耗一次。
