# FES 文字对象

本分支固定适配 CatSystem2 2.6.1.90。`fes::StringState` 提供文字对象的二维属性、两种消息配置、布局修改及字体继承状态。运行时已接入 `STRING`／`STRING8` 的声明、下层消息任务、普通布局、累计文本、分段播放、缓存查询和画布提交。日志及小说模式对象继续独立接入。

## 类型与构造

`STRING8` 固定选择 Unicode 实现。`STRING` 根据全局文字模式选择 CP932 或 Unicode 实现。`LOGSTRING`／`NVSTRING` 也分别具有两种实现，其名称带 `8` 的形式固定选择 Unicode。日志及小说模式对象另有独立状态，不能以普通文字平面直接替代。

调用 `StringState::new(encoding, &defaults, measurement_parameter)` 显式选择编码，传入 `message::MessageDefaults` 和原始度量参数。度量参数与字形参数分别保存。初始画面尺寸为 800×600，正文五级字号为 24，注音五级字号为 10；三个当前文字颜色均为零，独立恢复颜色为白色、黑色阴影和白色注音。不能直接用普通消息平面的默认颜色覆盖 FES 初始颜色。

`configuration_bytes()` 返回消息任务配置格式，含长度标签和提交尾部：CP932 为 0xe8 字节，Unicode 为 0x12c 字节。字体名保留 UTF-16。CP932 构造时使用传入的默认字形参数，Unicode 的对应字段初始为零；两者均原样保存独立度量 DWORD。

## 布局配置

`apply_layout(command, value, frame_delay)` 通过 `value(index, default)` 读取数值参数。调用方负责求值和数组广播；同一命令的参数只求值一次，各银行使用相同结果。未知子命令返回 false，不调用求值回调。数值参数读取失败时保留此前配置。

|子命令|参数与缺省行为|
|---|---|
|`view`|宽、高；分别缺省 800、600，同时写二维尺寸和消息尺寸|
|`color`|正文、阴影、注音各三个 RGB 分量；缺省零，各取低八位，Alpha 固定 255，同时更新恢复颜色|
|`margin`|四项边距；缺省零|
|`move`|字距、行距；缺省零|
|`shift`|绝对纵向偏移；缺省零，单独排队到后续媒体更新，不请求重配置|
|`ruby`|注音偏移；缺省零|
|`frame`|一项延时同时用于字符和句末；缺省或 −1 使用传入的 frame_delay|
|`shadow`|阴影和描边原始 DWORD；缺省零，关闭对应全局继承|
|`size`|五级正文字号；首项缺省 20，其余缺省为首项|
|`rsize`|五级注音字号；首项缺省 10，其余缺省为首项|
|`indent`|悬挂缩进 DWORD；缺省零，不归一化为布尔值|
|`weight`|字重；缺省或 −1 恢复全局继承，使用最近提供默认值中的 400／700；其他值原样保存|
|`escape`|标记解析 DWORD；缺省零，不归一化为布尔值|
|`fontfix`|字形附加参数；缺省零，保留全局继承标记|
|`prof_enable`|换行开关的原始 DWORD；缺省零|
|`profmode`|Unicode 按半角空格保持单词的原始 DWORD；缺省零；CP932 求值后跳过|
|`scrolltype`|逐字／水平渐显模式；缺省零，非零归一为一|
|`wipewidth`|水平渐显宽度；缺省 100|

这些操作通常设置配置更新标记。`weight` 保持该标记；Unicode 的 `view` 共用旧布局尺寸方法，更新值一写入配置正文 0xe8 处的字体区单元，独立配置更新标记保持。CP932 的 `view` 正常设置配置更新标记。库保留这两项基线行为。

`set_font(name, backend)` 接受 UTF-16 字体名和独立后端 DWORD，关闭字体名的全局继承并请求重配；遇到零单元时截断，容量不足返回诊断，保留旧配置。脚本 `layout font` 使用子命令后的完整剩余原文作为字体名，后端为零；`layout fontind [backend] [name...]` 先求值一个缺省为零的后端，再读取完整剩余字体名。字体原文为空时两者都使用当前全局默认名称。字体名保留引号，不求值其中的表达式，按 UTF-8 转为 UTF-16。原文入口逐个计数半角空格，连续空格也分别计数；不会重新按参数分词或去除尾部空白。

普通 STRING／STRING8 对 `vcolor`／`acolor`／`vacolor`／`pcolor`／`vpcolor` 依次求值最多九项参数，保持当前颜色；这些扩展颜色分派给日志类型。`fontind_sub`／`profmode_sub`／`prof_enable_sub`／`c_prof_sub`／`prof_sub` 求值一项，`shift_sub` 求值两项，普通文字对象随后跳过且不请求重配。未知布局（包括 `vdraw`）直接继续，不求值数值参数。字符集合的三个布局命令由运行时保存原文并下发，见下节。

`layout shift` 只求值一项，额外表达式不执行；数组广播共用一次求值。同轮多次设置保留最后值，`reset` 和文字清空保留请求。媒体更新在配置完成之后、文字及播放请求之前发送 470／491，每个银行消费一次；移位本身保留缓存光标，后续重新准备才更新光标。`shift()`、`shift_dirty()` 和 `clear_shift_dirty()` 分别查询保存的偏移、待提交标记及确认消费。下层绘制规则见[文字移位](message.md#文字移位)。

## 字符集合命令

`Scene` 接受普通 STRING／STRING8 的以下布局命令。它们独立排队，不请求重配；`fes::StringState::apply_layout` 仅处理数值布局，不接收字符原文。

|命令|待提交行为|
|---|---|
|`layout prof index characters...`|向指定类别添加字符|
|`layout d_prof index characters...`|从指定类别移除字符|
|`layout c_prof [index]`|清空类别；编号缺省零，仅接受 0～3|

编号表达式只求值一次，多银行共用结果。添加和移除各自保存一份累计原文：同轮连续调用拼接字符，编号取最后一次。例如先 `prof 0 A`、再 `prof 1 B`，更新时向类别一添加 `AB`。添加和移除接受原始编号，下层消息对象处理区外类别；清空类别四及其他区外编号直接跳过。

字符参数按第四个半角空格之后的完整剩余原文读取，保留引号、额外空格和表达式文字，不单独求值。缺少原文返回诊断；`""` 是两个引号字符。原文按字节保存，CP932 添加和两种编码的移除不做转换；Unicode 添加由下层按 UTF-8 解释。五类集合及移除的相邻字节编号规则见 [消息字符集合](message.md#字符集合配置)。

`reset`、`clear`、普通布局更新保留待提交请求。媒体更新在配置及纵向移位之后，先按类别 0～3 依次清空，再提交累计移除，最后提交累计添加；之后才消费正文和播放请求。每个银行分别消费，后续更新不重复下发。底层服务出错时保留尚未成功提交的请求。

## 全局字体更新

`font_inheritance()` 按字形参数、字体名、字重、阴影设置的顺序返回四项标记。初始时两种对象均继承字体名、字重和阴影；CP932 还启用字形参数刷新，Unicode 关闭该项。

`refresh_font_defaults(&defaults)` 只更新仍启用继承的字段，并请求配置更新。字形参数刷新写零；字体名、字重和阴影分别来自新默认值。显式字体名或字重不会被刷新覆盖。该入口同时保存最新默认值，供后续 `weight -1` 恢复使用。

`fontfix` 保持字形参数继承标记，因此后续全局刷新会把 CP932 的显式参数重置为零；Unicode 的该继承标记初始关闭，显式值继续保留。

## 字体枚举命令

字体列表由每份 Scene 独立持有，保留枚举顺序及重复名称。`Scene::font_names()` 在未初始化或初始化失败时返回 None，成功枚举到零项时返回空列表。

|命令|行为|
|---|---|
|`fontcom init [charset]`|先清除旧列表，再求值字符集（缺省 128），调用字体服务枚举；字符集 −1 表示全部|
|`fontcom count index`|把列表数量写入共享数值槽|
|`fontcom get font_index string_index`|依次求值两个参数，将字体名按 UTF-8 写入共享字符串；字体编号越界写空串|
|`fontcom search index name...`|先求值共享数值槽编号，再按完整剩余 UTF-8 原文查询首个同名字体；区分大小写，缺失返回 −1|
|`fontcom default string_index`|把当前全局默认字体名按 UTF-8 写入共享字符串|
|`fontcom add name`|将单个 CP932 直接文件名交给共享字体服务注册|

除 init／add 外，列表未初始化时跳过命令及数值求值；成功初始化的空列表仍执行查询。get 在缺少第二项时保留第一项的表达式副作用，search 在缺少剩余原文时也保留槽编号的求值。子命令区分大小写，未知子命令不求值。search 的原文沿用半角空格计数规则，保留引号与额外空白。

枚举由 `FontServices::enumerate(character_set, variable_pitch)` 提供已筛选的水平字体名。variable_pitch 使用独立全局度量 DWORD，零要求定宽字体，非零允许不定宽；顺序和重复项不由运行时重新整理。接口返回 UTF-16 名称，单项最多 63 个非零单元。服务默认返回未支持诊断；平台实际选择、度量与绘字继续由同一字体服务实现。

## 用户字形命令

普通 STRING／STRING8 接受 `object userfontobj source[bank]` 和 `object userfont character frame`。来源是已装载原始数据的 IMAGE 对象，使用 IDN −1 保留多帧资源。缺失来源解除绑定；不兼容来源类型返回诊断。参数缺失时跳过，userfont 缺少帧号时保留字符表达式的副作用；字符与帧号均截为无符号十六位。目标为全部银行时，参数只求值一次，再按银行顺序登记。

来源与映射先记入 FES 状态，在后续文字对象更新时下发；映射保留登记次序及重复项，每次变更重放整组映射。既有文字配置更新之前同步用户字形，新消息任务先完成初始配置。来源切换、缓存保留及实际绘制规则见 [消息用户字形](message.md#用户字形)。日志与页面引用类型的用户字形分发继续随对应对象整合。

## 运行时使用

`runtime::fes::ObjectState::String` 持有运行时 `StringState`，其 `layout` 字段为上述配置核心。`Objects::configure_messages(unicode, defaults, measurement)` 设置后续声明及重置使用的全局值；通过 Runtime 推进 Scene 时，自动从 `HostState` 的 `unicode_text`、`message_defaults` 和 `message_measurement_parameter` 同步。未提供默认值时使用 `MessageDefaults::default()`。`fes_message_frame_delay` 是 `layout frame` 缺省的延时来源。

工厂需要组合 `message::MessageFactory`，字体服务通过 `Runtime::set_fonts` 提供。装载期为每份声明记录创建直属消息任务；重复声明分别保留任务编号，对象上的当前绑定指向最后创建的任务。文字任务不在每次配置变化时重建。创建、布局更新、文本追加和字体服务出错后，继续同一 Scene 的预算续跑。

|命令|行为|
|---|---|
|`str`|替换累计文本，保留命令后的完整原文，包括引号；缓存剩余数暂置 −1，下一次媒体更新下发|
|`strsj`|将完整剩余原文从 CP932 转换为 UTF-8，再按替换文本处理|
|`apend`|追加完整原文；更新阶段只下发未消费后缀|
|`apendmark`|追加段标记，要求先初始化文本；CP932 使用单字节 FF，Unicode 使用 U+FFFF 的 UTF-8 表示|
|`clear`|替换为空文本；更新阶段清空下层页面|
|`reset`|恢复文字布局、字体默认值及继承标记，使用保存的恢复颜色；保留累计文本、消息尺寸和二维属性|
|`draw [segment]`|请求播放到指定段；缺省零，−1 表示全部；缓存剩余数暂置一|
|`skip`|请求当前段立即显示；完成查询缓存到下一轮更新才刷新|
|`isdraw`／`isdrawmark`|将缓存的全部／当前段剩余数写入 FES 局部变量零；不即时查询下层任务|
|`linecnt shared_index`|将最近一次追加后的行数缓存写入共享变量；不即时重新排版|
|`endpos [x_index] [y_index]`|将最近一次媒体更新的文字末端坐标写入共享槽；编号缺省 −1，多银行依次写入，最后一个有效银行保留|

媒体更新先提交初次配置或重配、纵向移位及字符集合操作，再消费文本请求、二维属性、播放和查询。替换文本保留基线的两次清空调用；成功追加的后缀在后续查询失败时也不会重复追加。配置尾部使用文字对象的 VRAM 位置，字形由既有消息平面写入共享画布，几何属性由平面协议维护。`stop` 仍沿用 FES 运动停止协议，不停止消息播放。

`StringState::text()` 返回累计的编码字节；`remaining()`、`remaining_segment()`、`line_count()` 和 `cursor()` 返回最近媒体更新保存的状态。下层消息命令 466／487 查询已准备布局的光标，469／490 准备页面并查询行数。行末换行不额外增加一个空行。475／496 按基线消费命令，保持调用方输出缓冲区。

`endpos` 先依次求值至多两个目的编号，再按银行顺序写入 X、Y；同一目的编号由 Y 覆盖，越界编号跳过，查询不推进消息或重新排版。普通文字的 `getpos2` 查询平面位置，遵循 [对象位置查询](graphics.md#fes-对象控制命令) 的父级规则。`lineinfo line [string_index] [number_index]` 仅向日志文字取得行内容；普通对象求值前三项后继续，缺少行号时直接继续。日志行查询随 LOGSTRING／LOGSTRING8 接入。

`LOGSTRING`／`NVSTRING` 及 `wait tag` 继续核实。页面引用、记录编辑等其余消息命令尚未接入。

## 文字完成等待

`wait string reference` 在开始时求值一次对象名称及银行表达式。目标存在时先结束本轮；后续读取 STRING／STRING8 的全部正文剩余数缓存，非零值（含 −1）继续等待。省略银行时按银行顺序跨过空洞和其他类型，只检查到首个非零缓存；显式银行只检查该银行。全部缓存为零或目标后来删除时，在检查当轮继续脚本。初始目标不存在或缺少目标参数时，对关键字 `string` 作数值回退，通常等待一帧。

有左击请求，且处于普通模式、ctrl 置位、取消开关开启中至少一项成立时，只向首个忙碌银行请求显示完当前段，本轮仍等待。查询缓存先于 skip 下发，后续媒体更新刷新缓存后才继续；若正文还有未播放段，全部正文缓存仍非零，等待保持。单独开启跳过模式不触发文字取消。

## 验证范围

八份原构造器配置覆盖两种编码及四种全局设置。548 组原布局调用覆盖十二类数值布局、字体原文、三种银行目标、缺省参数、负数、表达式副作用及全局字体刷新；逐项核对配置正文、二维尺寸、配置更新标记、四项继承标记、恢复颜色和共享变量。

常规回归使用合成配置和参数回调，固定 FES 初始颜色、字形与度量参数分离、布局更新位置、颜色回绕、全局继承恢复及失败后的状态保持，不依赖系统字体或游戏数据。

另以两种编码的 40 组命令场景、80 次媒体更新集中核对原入口的文本请求、配置下发及查询顺序。两项合成运行时回归覆盖全局编码选择、固定 Unicode 声明、段标记、局部／共享查询、画布提交、重复声明、任务回收、配置变化、字体失败重试及预算一／常规预算续跑。

补充 648 组布局调用核实类型门控、未知命令及移位状态；其中本批接入的 612 组、1,224 份完整配置与优化实现一致。31 条连续字体命令的枚举请求、数值槽和全部字符串表逐步一致。合成回归保留原字体注册检查，扩展类型门控、默认名称回退、字形参数继承、列表隔离、重复名称、查询顺序、空列表和初始化失败，均不依赖系统字体。
